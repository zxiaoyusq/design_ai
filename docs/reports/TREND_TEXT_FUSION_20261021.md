# 趋势纯文本融合与网页改造（2026-10-21）

## 范围与规则

- 当前 Skill 为 `prism-trend-semantic-clustering` 3.0.0；`prism-trend-themes` 是兼容入口。保留原版本共享编译器与历史全量结果，不覆盖旧输出，不宣称已重跑。
- 仅标题和摘要参与语义判断。Excel 的摘要继续标 `source_paraphrase`，不能冒充已阅读的网页原文；图片只在网页浏览中显示，图片像素、DNA、分类、标签和来源 URL 不进入语义请求。
- 每篇一个主去向，可有有依据的次级主题。主次关系均要求准确原文片段、共同定义与边界，并在新上下文独立复核；复核与最终主题、文字及分析上下文绑定。
- 正式趋势默认至少 3 个去重来源组，最低 2 个；主次合并时同文/同来源组只计一次。来源去重依据明确来源组、相同规范文章 URL、相同规范标题摘要；未知转载关系不能宣称已经识别。
- 不设 100 条或其他结果数量上限。按复核支持的来源组数、主归属来源组数、文章数降序，再按稳定主题 ID 排序；排序不是市场热度、增长率或商业潜力。弱、单源、未归类、不确定、不支持关系完整保留。

## 页面与接口

`/article-trends` 使用真实 API，不再只展示静态 30 篇。源表 `ref/趋势信息0930.xlsx` 共 8,833 篇，4 个网站来源、9 个分类，日期范围 2025-10-01 至 2026-09-18。原下载索引 `data/trend_data/trend_info_0930/trends.json` 关联共享 `data/trend_data/images/`，没有重新下载或处理图片。

- 全库服务端分页，关键词/来源/分类/日期筛选，完整摘要、原文链接、已有图片及放大。
- 可选筛选范围、跨页勾选、范围内最新 N 篇；手动勾选不再叠加后续关键词/来源/分类变化，但趋势日期对两种选择方式均生效。范围外勾选保留，不进入本次输入。
- 必须选择模型，先预估，再确认启动；范围、模型、门槛或 Skill 变化需要重新预估。预估只读，不调用模型。
- 网页真正启动时使用用户选择的**工程模型目录**，不把网页模型冒充当前 Codex 会话中的 Astra。本次开发验证未调用工程模型。
- 任务显示阶段、预算、进度、失败/暂停、手动继续、排名、主次引文、候选池、覆盖审计及完整 JSON 下载。

接口前缀 `/api/v1/article-trends`：`GET catalog`、`GET articles`、`GET articles/{id}`、`GET articles/{id}/images/{index}`、`POST preview`、`GET/POST tasks`、`GET tasks/{id}`、`POST tasks/{id}/resume`、`GET tasks/{id}/download`。

## 执行与恢复

任务独立存于 `data/result/article_trend_clustering/<task-id>/`。冻结文本、模型、Skill、编译引擎、阶段指令、分包预算和哈希；每次尝试保存真实请求、上下文身份、原回复、已知用量、时间及验收缓存。失败不自动重试，服务重启不自动重放，预算耗尽暂停并等待用户增额确认。

复用已有有界 DeepAgents：一次阶段仅一次模型请求，新建无工具上下文，禁止隐式摘要、子代理和自动重试。按实际文本长度分包发现，再逐页对齐完整主题目录，最后批量独立复核全部主次关系；不是每篇文章单独调用一次。

输入超长或回复不完整/不合规则明确停止，不截断文章、不发布未复核结果。文件锁与实际进程身份避免重复启动；恢复以持久化阶段与回执重建进度和已知消耗。不同摘要的未知转载需人工补来源映射后重新冻结，当前不声称具备完整转载识别。

### 六篇实际文字的 Astra 抽查

使用当前 Codex 的 `gpt-6-astra` 做发现，再以真正全新 Astra 上下文独立复核；未调用工程模型。固定 25084、24918、24601、11189、24753、25081 六篇，刻意选择跨品类圆润轮廓、局部半透明和综合资讯边界，不是随机或代表性样本。

- 6 篇全文标题摘要逐字回查 Excel 一致；图片、DNA、标签、来源 URL 不进入两次语义判断。来源 URL 仅由宿主旁表加入确定性去重。
- 4 个候选主题、7 条主次关系经独立复核：6 supported、1 uncertain。编译得到 **1 个正式共同趋势「以圆润轮廓组织柔和造型」**，由 3 个去重文章来源组支持（服装、置物架、圆凳），其中 2 个主成员、1 个次级成员；其余 3 个主题留候选池。
- 不因“半透明”把鞋底与声光装置强并，不把家具的高光饰面推广到服装；综合资讯未明确展开的隐藏构件机制判 uncertain，不借另一篇文章补证。25081/25084 同一 Allround 项目重复风险另行保留，来源组不冒充独立项目数。
- 输入、提案、逐关系绑定、真实分析/复核上下文、Skill 哈希、来源旁表及编译结果均在 `data/result/article_trend_validation_20261021/astra-sample/`；宿主脚本 `prepare_and_compile.py` 只校验这六篇，不调用模型。正式结果为 `result.json`。
- 该抽查验证所选文字上的边界和多文支持链，不证明全库归并质量或优于旧算法；未回放全量。

## 日期选择与历史 100 趋势展示补充

“开始趋势语义聚类”内直接设置趋势日期起止，按 Excel 文章发布日期含首尾筛选；空边界表示不限，设置范围时排除日期缺失文章。先取日期与选择范围交集，再按最新 N 篇截取；预估及确认弹窗显示日期，修改后旧预估失效。

页面新增历史结果入口，读取 `astra_consensus_20261001/final/` 的 100 个趋势、8,833 篇文章覆盖及 353 条候选点。保留历史排序、原来源组/文章统计、2026-10-01 编译时间和待人工审阅状态，不伪装成新 Skill 运行。每趋势展示最多 8 篇不同文章的原始证据并可回到文章详情；完整成员点与归并沿革从历史原始 `trend-clusters.json` 下载，下载不包含另存的候选池/覆盖旁表。历史接口独立只读，不修改源档，不作为可恢复的新任务。

## 部署边界

当前站点沿用既有无应用级身份鉴别架构。范围摘要和确认弹窗只防止错选/误触，不是认证；公网访问控制、用户权限及费用隔离需由受限入口或网关保障。新接口未临时加入另一套认证系统，部署风险登记在 `docs/BUGS.md`。生产使用前应确认访问范围，不能把浏览器人工确认当作防止外部 API 调用的安全措施。
