## 关键图形

第 2 页使用原八阶段：项目理解 → 并行研究 → 设计命题 → 方向建立 → 概念探索 → 深化协同 → 样机验证 → 方案确认。曲线从研究开始，在用户反馈后局部回升，没有实测比例。

第 3 页两排严格对齐这八阶段。下排为全项目愿景，不代表二期已经实装，也不声称达成零衰减。

第 5 页一期使用暖金实线框、已实装文字和三项完成/应用状态；二期使用虚线和规划文字。双板并行位于一个节点，用户反馈是两期衔接点。功能开发及产出物验证依据用户最新明确陈述；不把它等同于用户偏好已验证。

第 8 页：
主流程统一从左向右排为五段：资料输入 → 语义握手 → 选向与找图 → DNA 聚类 → 筛调成板。同一纵向基线上的箭头串联五栏，两路输入在左栏并列组织，情绪板原图放在最右栏。持续采集与制板周期单独作为底部说明，不构成第二条流程；窄屏保留横向关系和局部滚动。
趋势图文 → 趋势语义；用研图片、原因和访谈 → 用户语义；两侧握手 → 高潜候选。
建立方向—语义依据—原始资料—图片索引；设计师选向 → 取关联图 → 已有 DNA 与真实图聚类 → 人工筛调。
持续采集与按需制板分开展示。8000＋组、100＋组及 3—5 天均按用户汇报口径，不能当作当前网页单次任务统计。
