# 棱镜 · 图片DNA与局部CMF

负责中性的图像观察与解析资格。当前冻结生产链是R17原216字段协议，加local_cmf v1/v1.1/v1.2消费策略；按产物实际版本调用验证器。

1. 核原图哈希、来源索引、字典和生产者冻结清单。相同原图/版本已有输出时先复用，不能为了这次导出重跑整批。
2. 通过prepare生成提示、schema和身份清单。实际模型调用是独立的有界执行步骤，记录request、receipt、原始bytes及哈希；脚本prepare本身不调用模型。
3. 当前R17受验链要求Astra标准档、Fast关闭；更换模型按新候选记录。图片解析允许60秒或更长，历史运行给600秒上限，不把30秒当质量门槛。
4. accept先验编码、对象、父级、区域、参照和依赖，再对同一原图作另一上下文的实际视觉复核。只输出程序与复核双通过的known局部，同时保留完整账本和所有错误。
5. 将invalid_encoding、视觉unknown、not_applicable、未检查分别保留。v1.2只隔离已登记且能定位的坏槽；影子解码不是原模型输出，不能借局部恢复宣布原完整结果合格。
6. 下游必须使用官方verify_projection和范围感知消费接口。未投影不等于不存在；多件衣物误合成一个父对象等视觉归属问题不得用编码修复放行。

执行与依赖见 [交接契约](references/io.md)。
