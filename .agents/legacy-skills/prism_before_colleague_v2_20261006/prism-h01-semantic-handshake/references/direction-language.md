# 跨品类的设计方向表达

方向描述可复用的审美机制，不以行业、产品品类或使用对象划分方向。命名、概括和归并都遵守这一要求。

## 输出层级

- `title`、`design_question`、`shared_design_principle` 表达形态、比例、体量、轮廓、构成、细节布局、颜色组织、纹理或表面关系。不写“外衣”“运动衫”“手机”“家具”等品类名称，也不以“机背”“衣身”等某品类专属部位限定主题。
- 先提炼源材料中的共同形式关系再命名，不能只删除品类词、换成“产品/用品”，或仅改名却仍在问题和共同机制里限定同一品类。
- 按审美机制比较、聚合与握手。相同机制的不同品类可以支持同一方向；不同机制的同品类不强并。不能仅因文章或偏好属于另一品类而排除，也不要求每方向必须包含多个品类才能命名。
- 源品类、原对象、对象部位、实际使用场景、用户态度和否定条件保留在原引用、来源记录、变体、用户差异和适用条件中，不改写原文。通用主题名称不会把特定对象上的偏好自动升级为所有对象都接受。
- 若材料只支持某个具体实现，将其中有证据的形式关系作为方向，实施差异与迁移未决项写在条件中。没有可明确解释的关系时保留不足，不用“品质生活”“高级简约”等泛词包装。

## 命名示例

这些是表达层级示例，不是新增证据，也不是必须采用的固定目录。

| 原表达 | 通用品类无关的方向表达 | 提炼重点 |
|---|---|---|
| 克制口袋组织的工作外衣 | 功能细节的克制布局 | 细节数量、定位与整体视觉秩序 |
| 适度合身的连续外衣轮廓 | 连续贴合的流畅轮廓 | 轮廓连续性与适度贴合关系 |
| 适度放量的利落运动衫 | 舒展体量与清晰轮廓 | 适度扩展的体量与可读边界 |
| 柔和粉彩手机背色 | 柔和粉彩的低刺激色域 | 色相、饱和度及感受的共同关系 |
| 手机边框的克制条纹 | 边缘区域的克制线性节奏 | 局部范围、线性重复与主次构成 |

“功能细节的克制布局”的设计问题可以是“如何以数量受控、定位清楚的功能细节建立低干扰的视觉秩序？”。来源里的口袋仍在证据中；不用“如何为工作外衣设计口袋？”作为通用方向问题。其他示例同样只取实际被来源支持的关系，不补造比例、性能或接受程度。

## 交付前复核

检查每个方向的名称、设计问题和共同机制：拿掉源品类以后，是否仍能说明明确的形式关系？方向是否仍被某一品类专属词限定？是否仅换名却继续按品类划分成员或排除其他来源？概括是否增添了原文没有的特征或抹去真实条件？发现问题时定点调整主题及归并，保持来源证据可追溯。
