# 语义复核

- 方向 title、design_question、shared_design_principle 是否都采用跨品类的形式关系？是否仍含衣服、手机、家具或其专属部位来限定主题？按 [方向表达规则](direction-language.md) 提炼，不能只删标题词或换成“产品”。
- 是否按品类拆分同一审美机制，或仅因另一来源品类不同而拒绝握手？原对象差异应保留在证据与条件中；通用命名不能掩盖真实冲突或声称所有品类均已验证。

- 名称相似是否掩盖了不同的设计机制？仅“自然”“未来”“高级”不足以握手。
- 用研的正向依据是否真实表达偏好？品牌、职业、人格、题干、负向偏好、背景不能替代设计偏好。
- `existing_analysis`、转录/翻译及需求文本的来源等级是否如实保留？引文只是冻结文本，不自动等于采访原话。
- 同一用户多条观察不能重复计人数；分母为本次样本，不是市场人群。少数方向可以高潜，需明确人群范围。
- 是否读取趋势 lineage 中的局部机制、condition、effective_feature、rejected_inference 和点级范围限制？同文重复不能当多个来源支持。
- 是否审查所有负向及条件项，含未入簇项？分组理由能否同时解释组内每一条，还是用一句“不相关”跳过？
- 直接支持是否有真实的形式关系和相容条件？来源对象与情境差异如何限制结论，是否具体记录迁移边界？不能将品类一致当作支持，也不能仅用品类不同代替审美机制比较。
- 每个候选是否有单一主轴，合并/分开是否有证据？不能把互斥颜色堆成一个无限宽主题。
- 是否因凑数量、追求覆盖或多数票而收录弱项？没有高潜时允许零结果，并写出证据缺口。
- `applicable` 的约束有实际实施限制或冲突处置吗？存在未解决反证的方向必须降级。
- 结构校验只检查 ID、引文、归属、覆盖、模式和追溯；以上语义判断仍需宿主复核，人工选择不是自动获得的。
