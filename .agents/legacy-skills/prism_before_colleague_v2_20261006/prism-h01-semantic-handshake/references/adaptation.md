# 参考与适配

参考用户提供的 `ref/老师对接/prism-h01-semantic-handshake-v1.0.0.zip` 以及 `棱镜_用研语义聚类与第一次握手_两个Skills_20260930.zip`。两包中的 H01 文件逐项比较一致。

借鉴：语义优先、双边引用、三种握手模式、负向证据全覆盖、所有簇去向、候选与人工选择分离、输入冻结和可验证回执。

本地适配版 `1.2.0-local` 不声称与参考包输出协议兼容：

- 原包需要八份研究数据集和 replay compile；本版直接适配 `user_research_design_handshake.v1` 及 `prism.trends.semantic_clusters.v0.1`，沿用上游已有聚类，保留观察项与来源等级。
- 将完整输入冻结与模型取证包分开；先全簇摘要召回，再按候选簇分页回查。避免把上万证据一次塞入上下文，分页没有默认截断或排除语义。
- 在负向之外纳入 conditional 及带条件的观察项；审查可按相同适用性分组，代码仍要求每方向逐项覆盖且不能重复。
- 默认高潜方向至少两个去重趋势来源组；不得把整个趋势大簇的来源数当作某个局部握手主张的支持数。
- 人数与来源数由引用 ID 去重计算，不生成虚假精确评分。少数偏好不因人数少被自动丢弃。
- 冻结趋势点级范围限制与 lineage，保留上游待审和未知信息；不读取图片、local_vl_info 或 DNA 参与判断。
- 图片路径成为默认交付：按原文章 ID 连接图片清单，输出所有相关簇成员文章和全部原图引用，保留共用路径、失败与缺失状态。图片清单独立冻结，只在结果汇编时关联，保持语义输入为纯文字。
- 方向按共同审美机制组织，名称、设计问题和共同机制采用跨品类表达；原对象与场景留在证据和条件中，不能按品类拆分或仅用品类差异排除关系。通用命名不等于跨对象接受程度已验证。
- 新 Skill 入口独立，旧入口删除。网页后端仍依赖 `ref/design-trend-synthesizer` 的旧运行库；不迁移历史任务，不声称网页已切换新版。
