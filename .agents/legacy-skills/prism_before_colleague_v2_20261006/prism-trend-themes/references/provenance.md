# 来源与改造

本 Skill 2.0.0 于 2026-09-30 在用户授权下改造，名称沿用 prism-trend-themes。

- 参考 `ref/老师对接/棱镜_10项工作流Skills_20260928.zip` 内 `.agents/skills/prism-trend-themes/SKILL.md` 与 `references/io.md`。保留具体设计问题、文章身份、同源去重和趋势候选不等于用户支持的原则。
- 对照 `ref/老师对接/棱镜_用研语义聚类与第一次握手_两个Skills_20260930.zip` 的 H01 趋势输入契约输出纯文本 catalogue 和 semantic_clusters。
- 旧版依赖图文证据、ImageDNA、趋势质量与 prism_runtime；这些实现没有迁入。新脚本为适配文章 Excel 的读取、分包、精确引文校验及编译代码，不是对旧运行算法的逐字复制，不继承旧测试结论。
- 用户明确要求只使用文本。新版本以标题与摘要为唯一判断证据；local_vl_info、图片像素和图片派生描述均排除。没有将旧示例的固定主题数、数据规模或付费调用权限带入。

原始 ZIP 保持原样。本 Skill 的运行清单记录当前实际文件哈希；本地测试只证明读取、覆盖、引用和输出契约，不证明审美判断准确率。
