# 统一设计情绪与优先交付

## 统一的是判断和队列，不是删掉事实

新聚类不因历史 ID／CMF 标签而设两个独占候选桶或依次跑两套完整流程。保留七组具体观察、主导性、强反证和未知，从它们的组合解释设计情绪。当前方向可以以形态或表面关系为主，但不得因标签默认忽略其他显著冲突。

统一发现、归并和路由覆盖当前输入内原 ID／CMF 全部卡；`branch=DESIGN` 表示新组的比较模式，原卡分支保留为来源。旧模板可用于提出关系假设，不能把原分支或旧四个提名池作为新召回的唯一范围。当前执行若只验证了小样或接续旧池，报告相应范围，不声称已做全库统一比较。

已有设计卡不因这个调整自动失效。只在同一原图、同一对象、同一实际视窗和可追溯事实范围确实相同的情况下，建立重复证据的关联或去重投影；保留原卡号、分支、ROI 和原答指针。不能仅凭同图、相似名字或同材质把不同对象／不同表面拼成一张“完整卡”。整体与有设计表达的代表局部仍都可入板，不能因提速只留主物品或整图。

## 有少量好板目标时

先冻结目标、已有成果、剩余工作和预算；已获用户确认的条件直接沿用。优先交付 3–5 板不是承诺全部图片已被视觉比较，也不是授权放宽每板 6–10 图、同品类最多 50%、来源排重、真实取景或组合一致性。

1. 对已有实际选图结果作当前真实板面比较。合格者保留，不再重复提名、全库路由或追加长时间逐板审阅；布局过小与原图证据不足分开处理。
2. 若不够，选择少量可检验的关系方向，依据实际差距从全部冻结卡跨旧分支召回。可复用真实路由以减少请求，但旧池不足或已暴露系统性冲突时应扩池，不能只在同一批旧成员间反复排列。独立原图容量、共同关系和边界证据用于安排比较，不按代码颜色／风格分数选员；旧模板不是必须迎合的主题。
3. 当前池不足 6 个不同原图，无法在不扩池的情况下产生正式板，可暂不单独进入文字提名和看图；保留为扩展线索。不能将卡数当原图数，不能把来源未知计成必然不独立，也不能由这个容量门推出图片品质低。
4. 统一情绪下先比较池内 DNA，再用真实原图和冻结裁片选员。跨批候选可汇合，不按最初 32 卡的批次锁死成板。多窗仍需有界合流；视觉模型可拒绝、拆组，不以目标板数保底。
5. 同一次视觉请求先提出关系必要条件、允许变化与破坏条件，再逐员裁决兼容变化／主导冲突／未决，最后从允许成员成组。已判冲突或未决不能再用正向文字解释入组，最难协调成员对也须有具体证据。没有正式组时无需穷举两三图小组，但输入去向、强反证、事实疑义和未知仍须保存。

复发反馈跟随原对象与问题上下文进入请求，由模型逐条响应；更换板号不清除问题。新 B 输入保留事实、反证、限制和具体设计依据，去掉 A 对单图“温和／有序”等正向解释与质量等级，避免把旧自评当作跨图协调结论。反馈不是永久排除图号，旧模型的正向解释也不是保留名额。

没有适用候选时，明示该小轮不足并采用有依据的下一小轮，不自动恢复整套目录穷举。达到目标需要实际当前板的质量判断；功能 QA、文本提名和组数不能代替。不得把当前上下文比较称作独立盲审或人工批准。

## 接续不能让在途依赖漂移

图片附件必须在启动模型临时工作目录之前规范化为绝对路径，并核可读、SHA及冻结ROI；父进程中相对文件存在不证明CLI子进程可以读取。模型称裁片未提供时先核实际传图，标技术范围未验证，不算图像拒绝，也不回A盲补DNA。修正传输另版保留原答，只续受影响范围；格式成功门不代替真实图片上下文完整性。

用户从完整目录改成少量好板时，先收住后续发送，核已启动调用及独立子进程全部到终态，冻结合法前缀。原结果、失败和未发记录不覆盖；再登记新目标和新执行版本。修改实际规则、Prompt 或语义后新请求另建身份，不用旧结论冒充新版选图。

复用旧 ID 候选作统一情绪选择，不等于已经对 CMF 视窗或全库执行统一路由。必须分列历史实际召回、当前提名、当前看图、尚未比较的图片／视窗及目标是否达成；原分支保留出处，新比较模式另设字段。

## 入口与实际验证范围

`scripts/llm_group.py --comparison-mode unified` 是默认统一入口，显式 `legacy_branches` 保留旧分支路径。两种模式的政策、请求身份与覆盖分别登记；新程序支持统一队列不等于已在 1600 张图库完成真实运行。离线验证只证明调度、反馈和输出约束，审美效果另以实际小样与反馈判断。

2026-10-11 的 `.runtime/run_priority_emotion_pools.py`、`run_priority_emotion_history.py` 和 `run_unified_neighborhoods.py` 保持历史范围：前两者主要复用旧池，后者仅做少量混合邻域发现。其结果不能当成新入口全库召回、参考标准通过或本次修复有效的证据；旧数据及失败不覆盖。
