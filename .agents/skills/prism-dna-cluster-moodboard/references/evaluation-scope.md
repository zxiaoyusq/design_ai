# 小样验证与覆盖边界

用于修改提取、聚类、取景或反馈流程后的有界验证。验证范围与改动对应；改 Skill 不自动授权新的模型、图库重放或发布。

## 先验证执行，再验证审美

离线／假模型可验证：逐图缓存命中与拒绝、来源或原答篡改、阶段输入证据完整性、合包前后每卡候选不变、失败停发、全卡去向、局部修订不影响其他板、改成员／ROI／显示后旧审阅失效。0.13 另核统一队列确实覆盖原 ID／CMF、旧分支不限制新路由、冲突／未决不能入组、最难成员对不协调会阻断，以及反馈回应与真实成员一致。夹具必须标为合成，不把预设答案当模型的实际判断。

真实审美验证另需当次授权。优先使用少量未参与规则制定的图片，保留校准集与新验证集的区别，不重新提取已经适用的 DNA。不能以模型自评替代设计师反馈，也不能把传输／结构通过率称作视觉准确率。

## 有代表性的对比任务

选用下面与本次修改有关的情形即可，不强制固定样本数、固定材料或全部测试一遍。

- 跨品类、跨材质，但配色组织、轮廓／块面／线条及组合情绪协调的正例：检验是否被类别或材质硬分桶。
- 同色或同样圆润，但反光、构造或比例的组合显著不同的反例：检验是否被宽泛情绪词误并。
- 主物品旁有同级独立设计对象，以及有表达的代表性局部：检验对象绑定；另用无意义背景碎片检查误入。
- 混合历史 ID／CMF 卡，同时覆盖廓形、体量、连接、色面、表面尺度和光学关系；同一协调关系须有机会跨旧标签汇合，原标签不改变维度权重。旧分支验证仍按历史范围报告。
- 同一合法裁片采用不同版面尺寸：区分显示不可读与关系不成立，不用缩图迫使换成员。
- 拆到不同发现批次的协调对象：检查后续全卡路由确实有机会汇合；若未入板，回查是哪一阶段未提名／未看图，不直接归因 DNA。
- 已写出厚重／多层卷曲等强差异的卡：检查是否仍用同色、哑光或无纹样抵消，不能要求 A 为 B 已知的冲突全量重提。复杂造型本身可在其他关系成立的方向保留。
- 用已经复发的具体问题作回归：相同受影响对象换板号后仍能承接真实来源与原上下文；模型承认冲突却继续选入时应阻断。另提供上下文确实变化且关系成立的对照，确认没有形成永久图片黑名单。行为结果分别登记，不因字段齐全就宣称问题解决。
- 检查新 B 请求投影：单图正向情绪结论和质量等级不进入比较，七组事实、反证、未知和具体设计依据仍在；原 DNA 字节不变。不能通过把所有文字清空来获得反偏置测试通过。
- 对象配色已正确排除陈设／光照，但冻结视窗仍有突出竞争信息：检查是否区别物理归属与实际视觉影响；同图 ID 观察只有对象和视窗适用时才可补充 CMF，不自动跨对象合并。
- 同一图可证明整体轮廓但不能证明微纹理：检查是否按当前关系选择贡献；新结构的不可读成员应被拦截，但 Schema 合法不证明模型真的看清。源图不足、裁片过窄、图位太小分别定位。
- 同品类占比：离线覆盖 6／7 图最多 3、8／9 图最多 4、10 图最多 5，检验边界、超过 50%、未知品类、同一原图多卡及小组保留；确认不按代码自动删补成员。真实语义另核餐椅／办公椅、不同材料椅子及不同房间的整体装修没有被拆类，独立物品不因室内拍摄误计空间；fake 计数测试不能证明语义归类准确。

预期判断由设计师或独立实际看图者给出“支持／冲突／未决”及具体依据；没有金标准时报告案例表现，不计算伪准确率。一次失败不升级为全局图片黑名单或通用低彩度、同材质、整物展示规则。

## 图例教学的反偏置检查

先做零模型的请求边界检查：固定同一候选卡、分支和冻结视窗，分别不提供 brief、提供参考说明、换参考顺序／数量／颜色／主题／任意教学字段。发现、归并、目录、路由、选向、提名、视觉选择及定点重选的实际 system、payload、附件应不因这些教材内容改变；来源登记可变化。检查传输边界或实际保存的 Prompt，而非只检查构造器旁表。候选自身的颜色／细节必须仍在请求中，禁止以删证据来获得“不受颜色影响”。教材变动不改变 A 的请求身份；B 生产原则变动则必须产生新的调用身份。

假模型只能证明隔离和记录完整。另经授权做真实语义小样时，选择未用于图例的新图，优先覆盖：像参考颜色却有组合冲突；不像参考颜色但具体关系协调；参考未覆盖的高彩、锐利或繁复等有效方向；同一图片 CMF 有支持而 ID 不一定有支持。不同色相或高彩也不是保证通过的反向配额，预期结论必须来自具体图像。

对同一小样调换候选顺序与参考案例，比较成员去向、方向覆盖、正向理由和最强差异；不要求输出字面完全相同，也不要求换色后情绪和归属不变。因预算未看图与实际视觉拒绝分别记录。真实判断仍可能受模型先验或批次顺序影响，不能把隔离通过称作已经消除审美偏置。

## 固定报告口径

至少分别报告：来源池版本与抽样；ID／CMF 输入原图和卡数；可消费 DNA 覆盖；实际路由、提名、看图的唯一卡／原图；未选方向、缺事实、技术失败、预算未发和普通未入组选项；候选／小组数；AI 独立审阅及人工反馈状态；各阶段真实调用、复用、耗时。

新增统一模式同时报告 comparison_mode、统一队列实际覆盖、反馈匹配／响应／未解决数，以及离线测试、真实模型行为和实际板面对照各自范围。小样或旧池接续不写成全1600统一比较；当前三板是已知失败回归样本，不是独立验证集。只有少量真调用时逐例说明是否改正已知错误及是否误拒协调变化，不外推整体准确率或提速比例。

“没有被看图”不等于“模型视觉拒绝”；`needs_dna` 是待核事实缺口，不自动触发重提；`no_selected_direction` 不等于图片低质量。只有完成实际像素比较的当前板，才能声称对应范围做过视觉判断。

1600 图运行得到两张 CMF 板 AI 参考对齐，属于校准和流程实践，不是新验证集，不证明 ID 质量、全库召回、固定提速比例或人工批准。旧运行的已知问题与成功板保留，可作为回归输入，但不得伪装为独立新样本。
