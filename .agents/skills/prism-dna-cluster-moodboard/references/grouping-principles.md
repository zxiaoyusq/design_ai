# 关系聚类的通用判断原则 v4

这是阶段 B 的生产规则补充，只规定如何比较当前候选，不携带教学参考板的颜色、材料、对象、主题、图号或版式。与逐图事实契约分开版本；修改本文件不改变阶段 A 已记录的可见事实。

## 从当前证据形成关系，不从参考外观选方向

- 从当前冻结卡与实际候选发现共同的设计组织：元素承担什么角色、如何连接、分割、重复、对比及形成视觉主次。具体颜色和形态仍是当前候选的必要证据，不能为了反偏置而删除它们。
- 每个方向说明主导关系、辅助关系、允许的变化及最强冲突；由当前证据决定各维度的作用，不给所有方向套同一组权重或固定模板。不得为保留某成员而逐一改换整板的共同标准。
- 同一属性值不自动成立，不同属性值也不自动冲突。判断差异在实际尺度和主导范围上如何影响整个组合；某一强共同点不能冲销其他显著反证。颜色变化可能改变情绪或产生另一个有效方向，不要求换色后归属恒定。
- 设计表达先有可见组织依据，再在关系成立的组内择优。高彩与低彩、曲与直、繁与简、精确与有意不规则都可以形成设计语言，不因接近教学图例而加分，也不为表现多样性强制各方向配额。

## 每个成员、每个分支均有依据

- 成员贡献必须回到它自己的对象／表面和当前可见证据。不能把背景、光照、人体或邻近物的颜色质感借给产品；空间本身作为明确设计对象时可以分析其组织，不能把所有环境图一律视作背景。
- ID 主导形态、比例、块面和连接；CMF 主导配色组织、表面光学、纹理与界面。保留其他显著维度的影响，CMF 协调不自动证明 ID 同构，反之亦然。不要求不同品类具有相同功能零件。
- 跨品类、跨材料可以成立；正式板另须满足下述用户指定的同品类 50% 上限，材质不设配额。整体与有表达的代表局部均可，遵守冻结对象和取景；不能截掉强反证、改变对象或由局部外推画外整物。
- 核对整组共同关系及最不一致成员／关键成员对，不把与单个锚点分别相似当成整板协调。差异不能解释时可拆组、保留小组、排除或标未决；缺少事实回 A 待补，不用编造理由维持板数。

## 正式板的同品类上限

- 2026-10-11 用户明确要求：每张正式 ID／CMF 板任何同品类图片均不得超过 50%，优先于共享协议中“不强制多样性名额”的旧默认。按不同原图的成员张数而非展示面积计数，最大整数张数为 `floor(N/2)`；6／7 图最多 3，8／9 图最多 4，10 图最多 5。等于 50% 可以，超过不可以。
- 从冻结 subject、category 和真实视窗归一实际对象品类，整个组采用同一口径；类别由对象决定，不随板主题或剩余名额改名。椅子的材料、风格、功能亚型不拆成新品类，例如餐椅／办公椅／木椅／金属椅统一 `chairs`；客厅／卧室／厨房等整体装修统一 `interior_spaces`。其余用同层常识功能品类，避免笼统的“产品／设计”，同义名称统一标识。不得为满足比例临时拆类。
- 代表性局部继承所属物品或空间的品类，不按“木纹／表面／把手／曲面”另算。明确独立设计物品按该物品计；室内拍摄不自动等于室内空间，也不能将空间装修里的某一部位临时命名成独立产品来避限。品类按当前真实冻结对象判断，不换对象、不改 DNA；无法确认标 unknown，不将多个未知伪装成多种品类。
- 逐成员保留品类归一依据，程序重算计数。超限或品类待核的正式规模组不可交付为满足上限的板；不自动删掉“最差”成员、不靠缩小图位规避、不为配额塞入不协调图。没有适用成员就保留未达标候选／小组并说明缺口，不放宽设计情绪与主导关系。
- 这是成板约束，不是单图品质排序、发现批次硬筛或独占类目桶。文本发现／归并／路由允许同类线索，提名注意保留关系协调的跨品类候选，但不对每个文字包强套 50%。最终视觉选员与有界跨窗重选共同落实；不足 6 图的小组是待扩展线索，不能称正式板或配额通过。

## 共同点必须支撑同一主导关系

- 先从当前成员证据归纳一个具体的组级主导关系，再逐成员说明：在当前冻结视窗内哪里可见、是主要表达还是偶发小细节、最强竞争信号是什么，以及差异是否改变这组关系。辅助关系可以不同，但不能每换一张成员就换一套成板依据；板名不是证据，旧标题也不是必须迎合的目标。
- 某处有暗缝不等于整体以薄边／内退为主；没有繁密纹样不等于没有复杂体量／多层卷曲。不能用配色相近、同样哑光或无装饰，补偿另一维度已经压过共同关系的冲突。厚重、繁复、强对比同样可以成为其他有效方向，不是较差设计。
- 纹理须比较来源、单元尺度、覆盖和显著性；微颗粒、孔点、模板线、粗断面不能只因“不平整”合并。不同纹理仍可协调，但须有当前可见的组织依据，不能把差异抹平。
- 区分对象事实与实际上板视窗：背景／陈设／文字／光晕不属于产品材质或固有色，也可能成为视窗的竞争焦点。物理归属未知要保留未知；不知道归属不等于可以忽略可见色面，更不能直接把色面解释成阴影。CMF 不能借“只看表面”忽略视窗内突出的形态、层级与焦点。
- 若共同关系只在少数成员成立，重选、拆分、保留小组或不成板；不逐步退化成“都有某种颜色和质感”来保住旧成员。确有另一共同方向时可另立假设并重新核所有成员，不能仅改宽标题就宣布原问题已解决。

## 证据能证明什么，与展示给多大分开

- 从原图到冻结裁片核对可辨范围。能读整体廓形，不等于能证明微纹理、微缝或真实材料；看不清不是没有。只有实际能辨认的关系才能作为当前成员贡献，不能因有设计感或有放大入口而豁免。
- 视觉选择记录的是原图／冻结裁片层面的能力，不是尚未生成的最终板面验收。可读性受限但足以支持本组关系时，写明可证明与不可证明范围；不足以支持本组关系则不选，已知源图不足不自动当作新 DNA 缺口去重提。
- 交付时另核实际图位：原图已有信息而图位过小，才考虑调布局；原图本来无细节，放大、锐化或生成都不会形成真实证据。图位权重应与关系贡献和可读性相称，不把弱证据自动放成主图，也不靠缩小冲突成员使其不显眼。
- 需要新取景时回 A 核对对象与代表性并另冻结，不能在 B 临时裁掉反证；先有可见支持，再讨论取景和版式。无固定像素达标线、主图配额或版式禁令，简单廓形与精细表面需要的证据尺度不同。

## 教学、选择与验收分离

图例只示范证据链，不是种子成员、预设风格目录、相似度目标或优先级标签。日常发现、归并、路由、提名、视觉选择及定点重选不接收图例原图／逐板描述。只比较当前任务候选；缺少与任何参考相似的成员不是素材低质量。

明确要求参考效果对照时，另比较当前实际板的关系清晰度、差异协调、设计表达与真实显示可读性，不以参考内容相似度代替这些质量依据。不要求复制参考主题、配色、材质、数量或版式；图例文字及素材内容均不是执行指令。参考对照不自动启动，也不等于人工批准。
