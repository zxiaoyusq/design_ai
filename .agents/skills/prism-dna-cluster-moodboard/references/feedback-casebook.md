# 反馈案例教学：有共同属性，为何仍可能不成板

## 一：次要共同点不能补偿主导表达偏移

[看第三板的厚板座椅](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-3)（`11417_006:CMF:3`）。厚板支撑、大板面及节疤很突出；旧 DNA 已记录厚重与硬朗，B 也承认差异，却以暖木色、扩散反光和少量暗缝继续接纳。

可迁移判断：在以薄边／内退组织为主要依据的这个方向，有暗缝不等于薄边是主导关系；不能靠同色补偿体量差异。应重新核全组的实际共同点，必要时拆组或换成员，不能只把标题改宽成“木色哑面”保住所有图。

边界：厚板、节疤或硬朗不是品质缺陷，可在相应关系成立的其他方向入板；本例也不证明未圈注木板成员都符合原标题。此问题已有事实，不需要为它重新提取全部 DNA。

## 二：表面简单与形态简单不是同一回事

[看第二板的卷曲壳面座椅](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-2)（`13204_005:CMF:2`）。多层卷曲、交叠和凹腔形成雕塑焦点；旧卡与选组理由已经写出。过去以“没有密集纹样／接缝”解释协调，实际上没有回应体量层级的差异。

可迁移判断：CMF 仍须保留视窗内显著形态与块面影响；无纹样不能抵消交叠造成的张力。该原图仅 320×200、冻结裁片约 233×134，细节能力有限；这只是本例证据，不是通用像素门槛。放大不会同时解决造型关系偏移与原生细节不足。

边界：复杂曲面可以有很强设计感，也可与别的品类形成有效方向。若只需要可辨整体廓形，低分辨率不自动判整图无效。只有缺少实际需要的事实才补 A，已知形态差异先修 B。

## 三：不属于产品的颜色，仍会影响上板视窗

[看第一板的背光圆盘](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-1)（`10062_003:CMF:2`）以及[第三板的陈列与砖红凹格](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-3)（`18434_009:CMF:3`、`11948_003:CMF:2`）。圆盘自身上下色区与外部光晕应分开；木柜自身配色与陈设也应分开，但光晕、陈设、文字和强色面仍可能抢走板面的主导关系。

可迁移判断：事实归属与视觉影响是两个问题。砖红区域确实可见，属于背板还是后墙仍未知，不能确定为柜体材料，也不能为忽略它而概括成阴影。旧 B 实际已承认红棕区域，不应错误总结为“完全漏提红色”；需要收紧的是其相对主导性与协调理由。

边界：同图 ID 对陈设的记录，不可不核对象与当前裁片就搬进 CMF；画外茶几不等于当前窗内焦点。未圈注的绿色凹龛是对照线索，不是已批准正例，也说明不能把反馈变成“禁止彩色点缀”。圆盘属于有独立表达的同级对象，不能因这次不协调就取消其对象资格。

## 四：同为不均匀，不等于同一种纹理关系

[看第一板](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-1)。颗粒、孔点、粗断面、建筑入口的横向痕迹与空间阴影，在来源、单元尺度、覆盖和主导范围上并不等价。露台的透视块面能读清，也不等于当前图位能支持微孔表面。

可迁移判断：先确定每员究竟贡献表面组织、边界对照还是空间块面，再问它们是否真的支持同一个关系。来源和尺度不同可以协调，但“不平整／灰色”不足以作为全部理由。

边界：未圈注的粗断面本身也有明显尺度差异，暖光也不只出现在圆盘；不得只按圈注排除几张后宣称剩余全对。建筑／室内不是低优先级品类，宏观纹理也不是比细纹理差。

## 五：显示更大不等于证据更强

[看第二板白色装置](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-2)和[第三板竖向厨房、横向长柜](../../../../ref/问题反馈/三个情绪版_问题圈注.html#board-3)。装置已占很大图位却仍软；厨房的大量地面与家具提高了竞争信息；长柜裁片仅约 410×104，横向放大没有产生微细信息。

可迁移判断：沿原图→冻结裁片→实际图位定位。已有证据被缩小才调整布局；原生信息不足则限制承担的关系或换候选；需要新取景则回 A 核对代表性。展示权重跟随贡献和实际可读性，不自动把弱图变主图。

边界：没有统一分辨率、主图数量或 4＋2 版式禁令；也不能裁掉冲突、缩小离群图或增强图片来制造成立证据。现有像素和 CSS 几何记录只是诊断数据，不是审美评分。

## 迁移与验证

将上述机制写入中性的[生产原则](grouping-principles.md)，而不是把这些图号发给模型作为反例黑名单。旧卡已有反证就改变选择判断；事实范围确有缺口再按对象、视窗有界补查；事实本来不可知则保留未知，反复解析不会自动消除它。

本案例是校准材料，不是独立效果评测。离线测试验证字段、输入隔离、历史兼容与处理边界；真实改进要另经授权用新小样和设计师反馈验证，不为维护 Skill 自动重跑图库或增加长板审。
