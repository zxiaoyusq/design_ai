# 试跑发现与修正边界

## 1600 图流程后的通用执行优化（0.8）

此轮优化不新增审美禁令，不改关系提取 Prompt 或原 R5，不重跑原图和已发布板。将实际问题转成可复用的执行边界：

- 旧全目录下一层曾计划714个请求，其中512个单卡包；瓶颈之一是精确候选集合拆包。新合包保留每卡候选授权，报告实际包利用率与预算，不改变审美归属。旧519次调用产出的934方向后来已复用，不称全部浪费。
- 优先方向曾因末轮漏带代表／边界DNA、把未来整板验收前移而淘汰为0；新的阶段契约要求附齐已承诺证据，选向不要求种子已满正式板数量。新增优先模式属于通用入口，不再依赖固定两板项目脚本。
- 新A索引只在明确指定的旧冻结快照查找可核验、语义兼容的逐图结果。不同样本运行可以复用；原图同SHA但规则、上下文或对象不适用时拒绝，不虚构全库自动缓存。
- 首次两板参考对照均需修订，三张图主要是版面过小；木板不换成员，浅色板换一张对象归属待核的图后，新参考对照均对齐。显示、关系和事实问题分流，不据板审推测扩框或全库重提。
- 同类接口Schema错误曾产生44次失败调用，另有模型卡号越界。新入口按当前包限制身份，分离发送／本地Schema，首计划任务通过后展开该结构的并发，配置错误停发，不修原答制造成功。

本节说明触发依据，不是新版真实视觉效果的测量。两张CMF板仅代表原校准运行的AI对照，ID和全库召回未验证；后续按 [小样验证](evaluation-scope.md) 使用少量新材料，不将过去的反例或浅色／木质板固化成普遍风格偏好。

## 历史迭代

首次 500 图试跑确认了以下不同问题。按问题处理，不能将所有板审失败解释为距离阈值错误。首次结果使用紧凑特征 v4，不能由后续 Skill 升版倒推其已经满足新要求。

## 主体、整体协调与设计表达（历史 0.2.0）

本节记录当时实现；其中“只能主物品、ID 必须整物”的范围限制已由下文 0.4.0 修正，不能作为当前通用禁令。

用户实看后指出：部分成员来自房间或房子里的次要小墙面；品类可以混合，但整体颜色或设计与调性应一致；选图应优先有设计感。修正发生在主体观察、整体比较、簇内选图和独立原图审阅四处，不能只改提示文案或把裁框机械放大。

新版本在原图先定位主物品，分别保留事实框和主体展示框，增加绑定主体的整体可见观察及带依据的设计表达等级。背景／次要部位不具备入板资格；不同品类的功能结构差异不再作为跨品类设计语汇的硬冲突。设计等级参与簇内择优，不参与距离或替代整板审阅。原有较细的拓扑／纹理载体缺口仍需按实际证据处理，新增全局字段并不意味着它们自动解决。

首个真实5图批次发现CMF主物品特写被误套整物完整门：可见木家具端部是照片主角，不能等同背景小区域。新编译边界允许有原图截断说明的CMF主物品特写，保留画外未知及所有可见主体；ID完整要求不变。同次原答案离线恢复，旧失败另存。另由独立合成反例补齐同图主体身份／范围一致检查，以及未知颜色不得降低ID设计路线距离；这些是可复现协议修正，不是视觉准确率声明。

## 跨材质与五维组合设计情绪（0.3.0）

用户在执行中进一步明确：材质不同可以同板，形态、比例、色彩、材料质感、细节语言组合后的整体感受应相近。原局部CMF距离中的材料、光泽和纹理硬冲突不再适合此目标：不能因为镜面与哑光相异就自动否定一块板，也不能把同样圆润直接等同亲和。

新协议将可见事实与 `design_emotion` 解释分开，逐图记录五维组合依据、解释和未知；情绪轴只用于产生候选，独立整板审阅再看真实组合如何协调。暂停旧协议的新提交，在途结果保留；已有主体观察仅补缺少的情绪判断，不重提全部DNA。阈值和结构化轴均不是已证实的审美尺度，不从少量合成测试推断准确率。

## 同级对象与代表性局部（0.4.0）

用户指出第二次结果没有局部裁片，并补充“和主物品同级的其他物品也行”。实际核对完成的 27 板、207 个展示位：207 个展示框都包含所选主体，尽管 201 个成员另有更小的事实框。原因不是素材没有局部，而是观察与入组选项将展示框包含整个主体写成硬门；原图本来拍成近景不等于流程做了代表性局部取景。

修正为主物品／同级设计对象均可，整体／代表性局部均可；对象、事实、展示三层分别绑定。ID 局部只提局部可见造型与结构事实，CMF 局部保留真实表面关系；不同对象分别绑定 DNA、整体外观和五维组合情绪，不能共享一张图主角的判断。仍拒绝无独立表达的背景碎片，不为补数量强制局部比例。

原图与实际裁片双审：前者证明对象、上下文及限制，后者证明板上表达。允许突出代表性设计关系，不允许裁掉关键反例来制造一致。新增协议及少量离线验证不追认旧 27 板已满足 0.4.0，也不代表重跑了模型或更新了发布页。

## 粗情绪碰撞、实际共同关系与阶段拆分（0.5.0）

设计师反馈精确对应历史0.3两张八图板：CMF板 `BOARD-CMF-4a6f81923de2` 质疑01／03／07／08，ID板 `BOARD-ID-6e0b592ef38e` 质疑02与05／06、08与05／06。这些原板不是“已拒绝诊断”，旧AI曾判视觉支持；反馈是 comment_only，不能改作设计师正式拒绝或批准。

CMF01–06和ID01–07各自四轴完全相同，部分具体配色／体量／质感明显不同的组合却距离为0。原始观察已有不少差异，但距离没有消费；旧评审又看到了上游解释，倾向以“仍然亲和／温和”合理化差异。只降阈值、只改对象资格或禁止跨材质均不能解决。

0.5 把四轴限定为粗召回，具体分块事实的覆盖与差异优先于设计感选图，并保留每对候选对照。真实图像盲审需提供正向共同关系、每张最强差异及最弱成员对照，不能用“无冲突”代替共同设计依据。只读16成员复算能揭示部分原先被忽略的差异，但ID08／05的紧凑字段仍不足以表达全部质感冲突；因此分块均值不是视觉判定，未校准数值和这两张反例不证明泛化质量。

上一轮剩余440图观察约99分40秒，已有五路请求并行；本地最终聚类约3.64秒、0模型请求；27板独立审阅约21分40秒。另有46图情绪补查，原因是运行中新增定义，不是每次聚类都会补提。0.5 将逐图工作统一到独立预提取 Skill，终态后冻结，再让聚类读快照；缺项显式返回，不自动补查。拆分利于复用与阶段计时，不意味着首次全样本提取自然提速；单图请求相较五图小批的吞吐尚未实测。

本轮仅修改 Skill／实现并做极少量离线、假模型与浏览验证，不改历史图片、原回答、27板或已发布页面，不重跑500或全库。独立盲审的实际视觉改善仍待后续获授权的小样检查。

## 事实范围与展示可读性

观察框可能只有约 41×28 个原生像素，页面放大约 7.7 倍后依然缺少细节。也可能是 35 像素宽的竖条，表面真实存在而板上难以比较。生成交付时保留原图尺寸、当前 ROI 原生像素尺寸；浏览器截图旁证记录实际 CSS 显示尺寸与每轴放大倍率。数值用于定位问题，不设未经验证的像素硬门，不授予视觉通过。

文字声称排除书籍、灯带或相邻对象，不能替代像素范围确实排除。整体 ID 应核完整边界，局部 ID 应核其可见造型／结构；CMF 应核当前框是否仍能辨认材料光学和组织。只有关系受支持且当前审阅给出明确取景修正时，才可应用建议框；重新渲染后重新审阅。

## 紧凑字段丢失的差异

- **ID 部件关系与体量分布：** 交叉支架与低矮厚侧架可共享全部 11 个旧字段，距离为零。应定点补充可见的连接、主要方向及主体／留空分布；不能用品类标签分开，也不能靠收紧阈值区分相同向量。
- **CMF 纹理载体：** 平面的颜色碎斑与真实粗糙起伏，不应仅因均为 irregular / grain 混比。原 R5 的 TEX-001 区分真实起伏、颜色图案、光泽变化、透明变化、复合与未知，可作为有出处的候选语义。
- **组织层级和连续性：** 微观纤维、宽褶皱、构件铺排与离散碎石处于不同可见层级。线束不等于连续织物，孔隙网络不等于平整基底；增加字段须声明其实际范围和参照尺度。
- **光学信号范围：** 条材不透明可以与条间透光同时存在，不能把孔洞改写为材料透明。镜映、后景、孔隙透光和材料透射应在当前目标复核。

增加维度前，先检查对应旧 R5 是否有同图、同位置且适用当前目标的明确事实。未知保留未知；不要从关键词、物品类别或粗枚举猜新字段。只有受影响单元需要有界补查。验证新版本时保留旧数据和失败案例，再加入少量未用于制定规则的图片；不因首轮失败自动重提 500 图或运行全集。

本轮使用独立板审识别上述反例，部分候选保留为诊断结果。显示为“视觉待修订”不表示已解决字段缺口；新版 Skill 文档不改变旧运行的事实或结论。

## 来源身份层级

建筑／室内场景的具名项目与局部目标物件的产品系列是不同身份。来源复核应在理由中明确证据支持的是场景项目还是目标设计，不得以场景名称声称已经识别材料或家具系列。现有结果对该范围存在歧义时保留来源待核，不批量升为通过；后续结构化扩展可分别保存 scene_project 与 object_design，再定义排重依据。

来源未知不进入视觉距离，也不等于视觉不相容。视觉支持的板仍可先交设计师反馈，同时显示项目身份待核。
