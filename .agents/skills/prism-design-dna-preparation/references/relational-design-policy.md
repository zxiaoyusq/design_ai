# 可见设计关系与模型组板规则 v1

本协议用于逐对象设计卡和基于卡的模型聚类。它借鉴多标签 Skill v3.0.3 的“可见证据→同层风格候选”，借鉴模板聚类的组合条件、显著性、尺度和强反证；**不沿用其代码距离、权重、0.45 阈值或至少 3 图成板规则**。不是重新定义原 R5 或 192 个规范字段。

## 观察对象与取景

每张图可有主物品或同级、有独立设计表达的物品。建筑、室内、服饰和材料样本同样适用；背景小角落、随机墙面色块不因相似而成为设计对象。同一图不同对象分别记录，不能混用其颜色、轮廓和质感。

保存对象身份框、事实框、实际展示框（均为原图归一化 xywh），整体与代表性局部均允许。局部须保留能读懂的形态、表面或构造关系及其上下文，说明为何有代表性；不要求必须整物，也不得裁掉决定性冲突造出相似。对象出画则保持 whole_visible=false，不能称 whole_object 已完整可见。事实不能外推至画外。

## 七组比较证据

1. **配色组织**：主色、辅色、点缀的角色与主导范围；冷暖、明度、彩度及对比；色块如何依附于部件、轮廓和界面。不要把一点暖色概括成整体浅暖，不编造像素比例。背景及光照分开。
2. **廓形与比例**：直／曲及其组合，长宽高的可见关系、厚薄、收放、转折与张力。现代服装的剪裁、肩线、腰线、裙摆和分片同样可以形成结构化廓形；织物不等于无结构，传统／现代类别也不直接决定轮廓。
3. **块面与体量组织**：大小体块、片面、留白、凹凸、层级与分割之间的关系。跨品类比较视觉层级与分割密度，不比较功能零件的绝对个数。
4. **线条关系**：线的来源（轮廓／接缝／纹样／部件阵列）、路径、方向、粗细、间距、节律、密度、连续性与边缘锐钝；不能把物体外轮廓当作表面纹理路径。
5. **可见光学质感**：反光的强弱、宽窄、清晰／扩散、方向性、透光与层叠；镜面、高光、丝向柔光不能统一叫“亮”。材料只写可见外观，不断言真实成分、工艺、触感、价格。
6. **纹理与图案组织**：载体、单元类型、相对尺度、覆盖、粗细、疏密、对比、重复方式及方向。区分微观颗粒／纤维、表面纹样、宏观褶皱、构件阵列；区分抽象几何和具象图案。
7. **构造与细节语言**：边缘、接缝、接口、连接、装饰和层叠如何组织。比较克制／繁密、精确／手工偏差等具体表现，不以品牌、简繁或摄影质素代替设计感。

每组保存 observation、evidence、unknown。unknown 是未能判断，不等于没有；无纹理必须有可见依据，不能由缺字段派生。可见事实与“设计情绪”的解释分开。

## 风格、情绪、设计感的不同职责

- 风格候选从多标签知识库的 38 个 active ID 中取 0–5 个，同层记录支持、冲突、match_score 与 confidence；不强制主风格、不设 confirmed、不恢复旧仲裁和硬门槛。没有可支持候选就空数组，弃用的 TribeIdentity 不参与。
- 风格名与情绪词只帮助模型理解和多路召回，**不是入组凭证、硬分桶或代码相似度**。同风格可拆多板，不同风格标签可因可见关系协调同板。分数不冒充校准概率。
- 设计情绪由形态、比例、色彩、材料外观、细节共同解释，保留最强反向信号。圆润织物配浅暖色，与镜面金属配锐利接缝不能因为都圆润就归为同种感受。
- 设计感优先选择有明确比例、构造、色面、材料处理或细节组织的图片；设计表达与照片可读性分开。先有协调关系，再在组内选设计表达更清楚、完整、有辨识度的成员，不能以强设计感豁免离群。

## ID 与 CMF 如何共用、如何区分

两支都核对实际展示视窗和同一对象上下文的配色、廓形、块面、线条是否协调。ID 主导依据是形态／比例／构造的组合；CMF 主导依据是色面／表面光学／纹理及界面的组合。CMF 不要求不同产品轮廓完全相同，但显著轮廓和块线差异不能压过共同表面表达；ID 也不能忽视高彩色、表面和细节造成的明显不同情绪。

允许跨品类、跨材质，不强制多样性名额。维度可以不同，但模型须说明差异为何协调。不是要求七组逐字一致，也不是允许某个共同点抵消任何其他冲突。

## 六类反馈对应的反证检查

| 常见伪相似 | 必须比较的组合差异 |
| --- | --- |
| 都是黑色 | 主辅色组织、明暗、塑料感／石质感等可见表面、反光和整体情绪 |
| 都有细边界 | 可见分割密度、连接显露、层叠和体块层级；不比跨品类零件数 |
| 都有光泽 | 光带方向性、清晰度、扩散与微细表面；不把塑料／织物名称变成品质排序 |
| 都有不规则纹理 | 主导红色与低彩中性色是否冲突，不能让纹理覆盖配色反证 |
| 都有装饰图案 | 具象／抽象、单元尺度、密度、对比、覆盖及重复方式 |
| 都有线性起伏 | 宏观折面／构件阵列与细颗粒纹理的尺度、路径、锐利／模糊边界 |

反馈不是图片黑名单，问题是当时那组关系。不同新上下文可重新选择同一图片。上游趋势标题、情绪板旧名和旧 PASS 不能作为正向证据。

## 从关系模板到实际板

模型根据实际卡片发现模板，记录共同组合、允许变化、强冲突、代表成员和边界成员；不能先起好听标题再凑图。跨批合并时查看这些证据，不只合并同义标题。所有卡仍须参加后续路由，包括早期离群和未知，不静默丢弃。

最终成员由大模型看真实原图及已冻结裁片选择。核对全组共同关系、最强差异、最不一致成员与代表成员，不接受 A 接近 B、B 接近 C 就自动合并 A/C 的链式推断。证据不足或实际视图矛盾时可拆组、保留小组、排除或列出待补 DNA；在聚类阶段不补写单图事实、不偷偷改框。

每正式候选板 6–10 个不同原图，目标 8；不足 6 保留小组，不强凑。每文章／已知项目最多一张，别名也参与去重；未登记项目仍是 unknown，不能宣称来源完全独立。秀场最多 floor(0.3×板图数)，服装／有人不自动是秀场，未知保持未核而不当 no。

模型选图与冲突检查属于聚类本身，不称独立盲审。独立板审和人工批准分别保留状态；当前用户已要求跳过额外耗时逐板审阅，不自动追加该阶段。
