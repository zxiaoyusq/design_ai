# 棱镜｜ID风格第二次握手

读取 [原生H2合同](../../prism_skill_support/references/contracts.md)、[ID接口](../../prism_skill_support/references/native-api.md)。使用id-reference-board-v5；当前实现是家族约束下的实际视觉选组，不是全库无监督向量聚类。

输入冻结brief、广候选manifest、原R5已知观察、quality bundles、对象声明及实际视窗。prepare重放完整来源，不信supported缓存。相同字节别名记录全程用alias-id，不能中途换回不兼容入口。

比较当前状态整件主导轮廓、比例、体块/边界组织、结构主次。用独立载体说明同一个设计关系，不以功能、品牌、颜色或参数ID相同当成组证据。ID卡不应只剩材料局部；只要部分完整关系可用，也必须明确声明范围而非假完整。

全候选去向可查；视觉导航若再次精选必须保留数量、理由及遗漏，不能隐藏地把100图又缩回6–7图。最终按本项目约定精选约10张，按文章、SHA及已知项目/系列排重。

原负向和未来产品义务原样携带；逐条按人、对象、程度和当前范围解释。未来实物阈值不能默认拒绝所有参考，也不能改成已解决。遇到原负向引用缺口，可使用 [future-reference可选入口](../../prism_skill_support/references/native-api.md)，保留原数组，不造义务索引。

真实提案交accept_grouping；不能为数量或格式改变预期。分组通过不等于整板通过。取景需要处理时交 `$prism-reference-image-preparation`，实际成板交 `$prism-board-review`；只有原生整板门实际接受后才能称原生H2整板通过。
