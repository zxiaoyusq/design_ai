# 情绪板网页名称兼容入口

完整流程由 [prism-workflow](../prism-workflow/SKILL.md) 路由：具体设计转译及material-brief→广候选原图/R5→当前目标绑定/原生品质→实际裁片检查→ID/CMF第二次握手→处理修正→独立整板审阅→交付。

不再只凭DNA文本给4–8张主风格主题生成可通过情绪板。此项目新成板要求10张/10可核实独立项目，裁后主关系、第二强信号、尺度与一致性均须实际阅读；板审可以否决并换图，补齐合格第10张前不得通过。

使用 [prism-moodboard-delivery](../prism-moodboard-delivery/SKILL.md) 保存完整原生证据；仅由网页adapter投影到现有展示结构。旧页面历史档案继续只读，不把缓存supported/PASS或机器格式检查当原生视觉结果。当前任务仅更新流程，没有恢复模型执行授权。
