# 棱镜｜可见关系与选材说明

输入已验证H01选择、语义边界、当前设计师参考、图数政策；输出 visual-family.json／material-brief.json与原生brief准备数据。读取 [可见家族合同](../../prism_skill_support/references/contracts.md) 和 [选材前置合同](../../prism_skill_support/references/material-contract.md)。

显式写出“语义问题→这次选择的可见设计关系”。比如紧凑对应某种收拢方式是一条探索，不是用户已表态喜欢该造型。趋势簇可以宽，视觉家族要能在多个独立项目中看出共同关系。

先写比较单位、主关系、两三项必要可见证据、允许变化、会抢走主题的干扰、原图/局部尺度、素材处理要求、来源容量和数量政策。主关系可以是轮廓组织、表面关系、配色等；不能把本次槽纹案例的低彩度和五条槽纹变成通用规则。

ID比较当前声明状态的整件形态、比例与构造；CMF比较指定表面或同物件相邻界面。也可以是色域/光感家族，不要求每次都有纹理。颜色相同、功能相同、关键词相同都不足以证明家族一致。

在低成本原图预览阶段校准可见性与独立来源容量，明确每类“保留全貌/局部取景/补原图/需展示增强/不适用”。正式候选解析和最终验收前冻结规则；后续改变是新版本，受影响材料重审，不改原预期凑通过。

校准图是参考，不参与新候选计数；用户PDF优先于机器模板。可参考共享assets/calibration和随包linear-relief案例；它们不是未见样本金标。

保留原H01负向、未决义务及本次设计转译身份。在本合并入口内部完成供应检查；素材足够后固化选材条件。完整新流程仍需在新数据上检验，不把单板试验升级为六算法整体PASS。
