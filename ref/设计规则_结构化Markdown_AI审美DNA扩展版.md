# AI 审美洞察设计 DNA 扩展（新增内容，非源 Excel）

## 一、适用性结论

当前 Markdown 的六个设计元素模块，已经可以支持 **V0 级的手机外观粗粒度标注、风格初筛和基础检索**，但不足以独立支撑“抽象审美参数化、稳定 DNA 提取、生成约束、方案契合度评分和趋势聚类”。

| 评估维度 | 当前状态 | 主要问题 | 扩展方向 |
| --- | --- | --- | --- |
| 对象属性 | 已有基础 | 形态、相机、颜色、材质已有标签，但部分粒度较粗 | 补充比例、连续参数、区域定位和关系字段 |
| 元素关系 | 明显不足 | 缺少构图、视觉层级、留白、节奏、平衡和对比语法 | 新增构图与视觉秩序模块 |
| CMF 计算 | 部分具备 | 主要材质标签无法表达不同区域之间的材质与工艺关系 | 新增区域 CMF 映射、光泽、反射、边界和层次 |
| 多视图完整性 | 不足 | 当前内容明显偏重背面与相机，正面和侧面覆盖弱 | 新增正面与侧面 ID，并引入 not_observable |
| 风格到感知 | 已有关键词 | 用户感知为离散词，难以聚类和计算距离 | 新增连续语义坐标与证据链 |
| 品牌与系列 | 基本缺失 | 难以判断家族延续、签名元素和竞品差异 | 新增品牌编码、系列关系和趋势属性 |
| 模型可靠性 | 缺失 | 未区分“没有该元素”和“图片中看不见”，也缺少证据与置信度 | 新增统一记录结构和多视图证据规则 |

> 结论：原内容不应删除，可作为 **基础标签字典**；新增内容应作为 **关系层、参数层、语义层和证据层** 叠加。

## 三、统一 DNA 记录结构

每个字段不只输出一个标签，而应同时保存“值、位置、证据、可见性和置信度”。建议统一结构如下：

```yaml
dna_field:
  field_id: CAM-07
  module_id: DNA-M04
  name: 镜头尺寸层级
  value: 一主多辅
  value_type: enum
  region: camera_island
  view: rear
  observability: observed        # observed | inferred | not_observable | unknown
  confidence: 0.93              # 0~1
  evidence:
    bbox_norm: [0.06, 0.05, 0.43, 0.40]
    description: 最大镜头直径明显高于其余两枚镜头
  source: ai_extension
```

| 字段 | 要求 |
| --- | --- |
| observability | `observed` 表示图像直接可见；`inferred` 表示感知推断；`not_observable` 表示当前视图不可见；`unknown` 表示可见但无法可靠判断。 |
| none 与 unknown | `none` 是确认不存在；`unknown` 是无法判断，二者不得混用。 |
| region | 建议统一为 whole_body、front_face、back_cover、frame、camera_island、lens_ring、button、logo、decoration、port 等。 |
| view | rear、front、left、right、top、bottom、three_quarter、detail；多视图分别提取后再聚合。 |
| evidence | 关键字段至少保留 bbox 或 mask；语义字段至少引用 2 个观察型字段。 |
| confidence | 颜色、材质和人因感知易受光照与视角影响，应单独设置低置信度阈值。 |

| RULE-03 | 单图不可见的正面、侧面、真实厚度和材质触感必须输出 not_observable，不得猜测。 |
| RULE-04 | 颜色需先做白平衡与高光/阴影抑制；特殊色效与主色、辅色同时标注。 |
| RULE-05 | 材质判断至少综合反射、粗糙度、纹理、边缘高光和区域连续性；低证据时输出候选分布。 |
| RULE-06 | 构图字段以区域关系为依据；非对称不自动等于动感，复杂不自动等于装饰。 |
| RULE-07 | 风格标签先校验源表中的必要项与排除项，再使用语义坐标做排序和冲突仲裁。 |
| RULE-08 | 语义结论必须附 evidence_refs，例如“科技感高”至少引用金属、几何秩序、结构外露或光学效果等字段。 |
| RULE-09 | 多视图冲突时保留各视图值，并由可见面积、视角质量和 confidence 加权聚合。 |
| RULE-10 | 所有数值字段保存原始值与离散标签，避免只有“高/中/低”而无法精细比较。 |

## 八、契合度评分建议

对“目标 DNA—生成方案”或“参考图—候选图”进行评分时，建议使用 **硬规则 + 可见性覆盖 + 置信度加权相似度**，避免仅比较风格名称。

```text
若命中目标风格的排除规则：标记 disqualified，不进入同风格排名。
字段得分 = similarity(target_value, candidate_value) × candidate_confidence × observability_weight
模块得分 = Σ(字段权重 × 字段得分) / Σ(可比较字段权重 × observability_weight)
总契合度 = Σ(模块权重 × 模块得分)
可见覆盖率 = 可比较字段权重 / 目标全部字段权重
```

| 评分输出 | 说明 |
| --- | --- |
| overall_match | 总体契合度 0–100。 |
| module_scores | 按形态、构图、相机、颜色、CMF、纹理、细节、语义分别给分。 |
| hard_rule_result | 必要项是否满足、排除项是否命中。 |
| coverage | 当前图片实际可比较的 DNA 覆盖率。 |
| top_mismatches | 贡献最大的 3–5 个偏差字段。 |
| drift_direction | 相对目标向哪个语义轴偏移，例如更厚重、更张扬、更科技。 |
| evidence_refs | 每个扣分点对应的区域框、原始数值和判定依据。 |
