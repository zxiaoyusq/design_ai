# 棱镜｜设计情绪与整板评审


先读[设计师反馈校准](../prism-visual-family/references/designer-calibration.md)与[整板合同](../prism_skill_support/references/review-contract.md)。输入当前板、原图/视窗、冻结风格假设及research-binding。隐藏标题后先判断整体，再核对作者解释。

逐图指出独立的可见支持维度、组合的整体感受、核心冲突和局部差异；检查最不一致的一对。握手维度多不是同义词计数，也不设机械的“几维即通过”。核心反向关系不能被几项弱共性抵消。

核心冲突应替换/拆组；局部边缘稍锐、功能圆件和有限光哑差异，按面积、位置、对比、结构角色判断是否可容纳。不要追求所有维度完全同一；也不要把R4容许局部差异扩成所有旧板通过。

复核每张在成板尺度直接可见，人物与产品在柔软/雕塑/规整等主导关系上相容，跨品类成立范围如实报告。至少8张原图、项目去重、来源身份和研究绑定同时核对，但机械条件不能代替审美。

用`style_board_check.py --board board.v4.json --out check.json`查当前文件SHA、计数、ROI和绑定完整性；它不看图、不输出审美PASS。`review.json`另存实际审阅者、上下文、板哈希、逐图问题、可容纳差异、整板结论。无独立审阅只能写作者自审，不能编造。

AI判断、用户反馈、设计师反馈和原生H01/H2状态分列。实际用户研究验证未做就保留未做。所有正负反馈绑定对应版本/图片/范围，不能互相覆盖。具体问题有界修订，缺图时保留不足而不凑数。
