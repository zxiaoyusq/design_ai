# 棱镜｜范围与全流程导航


先读[总合同](../prism_skill_support/references/contracts.md)与[阶段路由](../prism_skill_support/references/routing.md)。接续工作先核实已有证据和最新反馈，沿用已明确的授权，不让用户重复说明。

冻结：研究问题、输入版本、用研/趋势绑定、研究层级、方向选择身份、候选范围、实际读图覆盖、每板数量、来源政策、原图处理范围、模型配置、费用/调用预算和输出位置。未知单列，不把示例值当用户指令。

当前项目是总体风格研究：用研与趋势语义作为前提，视觉与解析共同判断；每板至少8张原图，不硬凑；人物与跨品类以设计情绪相容为条件；允许局部相容差异。方向数不预设，候选池不等于最终图数。没有通用秀场百分比、固定Top5或固定5×2版式。最新明确指令覆盖这些项目默认。

当前路径：证据入库→两侧纯语义聚类→H01及有依据的选向→扩充有来源的候选池→总体风格假设→原图与解析联合筛选→ID/CMF复核→成板→评审→可编辑交付。已有DNA可复用，新解析按需要补足；DINO已停止，不自行恢复。只有使用冻结R5模块时才采用其固定配置，其他判断遵循用户当前模型选择并记录实际身份。

`workflow.py init --config project.json --out new-run`冻结配置并记录路径；`status`读取状态；`record`记录真实产物。它不自动调模型、不自动安装或全库执行。每个阶段可prepared/partial/complete/failed，跳过或未做的正式门记录not_executed；不要把视觉试板冒充正式H2。

用户要求新方向时先做一个能实际审阅的小样；用户已明确要求多板的既有任务按其范围执行，不额外增加确认步骤。具体问题持续三轮无改进则报告证据、换方法或缩小断言，不用改标准强行通过。
