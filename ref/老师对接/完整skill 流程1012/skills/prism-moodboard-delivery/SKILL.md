# 棱镜｜情绪板与原文件交付


按[原文件交付](../prism-visual-family/references/source-handoff.md)与[完整交付合同](../prism_skill_support/references/delivery-contract.md)执行。先交当前版本的实际板和诚实状态，再附研究/来源与复验记录。

每板至少保留：高清纯图版、沟通版（短说明压在板内）、完整原始图片、可逆裁切与位置参数、逐图来源表、research-binding、review与规则版本。PPT/SVG/HTML等可编辑格式逐图逐文本可编辑；没有原PPT/PSD时标“按原板复建”，不可称原生设计源文件。

指定旧版则给对应旧版，不用最新版替代。保留版本日期与反馈范围；待改候选不标设计师已认可。示例排版不是当期风格通过证据。

素材、依赖用包内相对路径，运行时重新绑定绝对FileRef与SHA；不依赖作者电脑临时目录。给完整性清单、入口说明与解压复验结果。原图/字体未随包时明确标出依赖与影响，不能宣称可完整离线复建。

区分全套方法工具包、具体项目数据、原文件交付包。完整图库与私有访谈是输入资产，不把它们说成skill内置；安装不自动下载图库、发送消息、发布或启动模型。向同事发送须有用户明确发送指令。
