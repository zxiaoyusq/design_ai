# 棱镜｜总体风格与视觉家族转译

## 目标与依据

把设计师选图的可见关系，转成选图、裁切和整板判断规则。最终访谈板让被访谈人直接观看并选择，设计语言必须在成板尺寸下一眼可见，不靠标题和口头说明补齐。

当前项目自2026-10-10进入**总体风格层**：用户提供三张设计师标准板，要求完成度参照第三张。总体风格任务先读[三张标准板与风格层规则](references/style-level-review.md)，实际查看对应参考图片。[用户原话及参考哈希](references/style-reference-evidence.json)保留依据。第三张的“原质新生”是一个主题案例，不是所有新板必须使用的风格，也不代表其中材料与产品信息已核验。

总体风格选图还须使用[多维关系与配色收敛](references/multidimensional-style-review.md)：用户最新反馈指出图之间共同支持的维度太少，“多彩”和“粗颗粒”等宽标签内部仍需细分。该页提供配色关系、形体与表面组织的核对方法及实际反例；不是要求所有维度完全相同，也不设置维度数量的通过门槛。

本轮继续制作或精修板子时，另读[设计师反馈校准](references/designer-calibration.md)。它区分核心设计情绪冲突与可容纳的次要差异，收录柔塑、深色有序、银壳的实际反例。2026-10-12的新反馈允许现成图保留局部差异，不等于撤销此前逐图问题或认定整板所有图片通过。

早期元素／CMF依据是用户提供的《250221 CMF image test for EE1》14页参考板。它是CMF参考；原文件只有G1—G14编号，没有主题名称。本文及[逐页图谱](references/designer-board-atlas.md)的主题解释属于AI转译，不能标为设计师已确认标准。G13、G14边界较弱，不强行解释成单一材料家族。它们可以提供细节证据，不能单独替代新的总体风格标准。

## 先确定研究层级

当前项目沿用**用研语义与趋势语义握手后的方向**。选图前读取该方向的真实用研原话、对象与受访者、趋势语义父簇、正向／负向和未决边界；换图与精修须保留这些绑定。视觉与解析共同判断，解析补足关系及语义来源，不能替代照片可见证据。不得因视觉相似重新定义用研偏好，不把外部补图自动记成原语义簇成员。缺少绑定时明示视觉试验及待补内容。操作细则见[上游衔接](references/upstream-protocol.md)。

- **总体风格**：先写完整设计语言的假设，说明形体／比例、色材表面、构造／细节怎样共同组织为相近的设计情绪。条件是组合可见且相互协调，不是逐项完全一样，也不是共享一个圆角、颜色或纹理。逐图和整板都审这个组合。
- **元素／局部ID或CMF**：围绕一个明确接口、形态或表面关系研究。可以独立交付，但不能把局部一致升级为总体风格通过。上轮`outputs/visual-direct-expanded-20261010/skill-restart-r1/B01.jpg`属于这一层，不沿用其自审结论证明新风格板成立。
- 用户当前任务默认总体风格；只有明确要求研究某个局部时切回元素层。风格任务先选能看清产品形体及色材组织的图，再用细节图强化证据；不得把所有图片裁成匿名局部以掩盖不同整机的风格差异。也不强制所有图片都必须是整机全貌。
- 跨品类优先用于检查同一设计语言的成立性，不设品类数量硬配额。相似手机型号不能冒充多种品类；为了多一个品类加入弱匹配图，降低了研究价值。若只在同一品类成立，如实声明覆盖范围，不能声称已证明跨品类。
- 先审选图和风格成立性，再审成板精致度。主题背景、抠图、排版和名称不能补救素材不一致。遮掉标题及主题文字后仍应能判断同一风格。

## 先确定比较什么

- **ID**：形体、比例、轮廓、体块、曲面转折及构造组织。用能看清所声明形态的全貌或足够范围的局部；检查色材、表面与细节语言叠加后是否仍传达相近的设计情绪。当前CMF参考不能直接证明一套ID风格标准。
- **CMF**：可见颜色、材料外观、表面处理及相邻表面的搭配关系。可以看局部，但保留支持该关系的接缝、边框、厚度、按钮或连接位置。
- 同一照片可用于ID、CMF或多个方向，分别声明比较范围和证据；不按来源类别一次性互斥分配。

## 每个家族先写一条可见主关系

总体风格模式先按风格规则定义完整语言，再从中提取可见主关系；以下局部关系示例本身不足以作为总体风格定义。

先声明本轮是重建某张参考的主要关系，还是用参考校准标准后另建方向。另建方向不必复制参考材质与题材。参考中的主趋势与例外分别记录；选定子方向的必要条件不能反过来冒充设计师整板的统一定义。

用“什么主体＋什么表面／部件＋怎样相接或组织”描述；单一强表面特征也可成立，不强求每板同时覆盖C、M、F。

例如：浅暖主体与暖金属外观细边相接；织物面包覆硬框并露出连接边；低彩度主体在按钮或端件上使用局部强色；镜面外观沿有明确边界的曲面连续展开。

避免仅用“高级、科技、自然、圆润”或“木纹、白色、亮面”作为合格依据。至少说明共同关系、必要可见证据、允许变化、干扰因素、最近似方向的区别以及取景范围。

## 再确定整体设计情绪

设计情绪指形态、比例、色彩、材料外观、光泽纹理与细节语言共同传达的整体感受，例如亲和松弛、冷静精密或活泼轻快。它是内部选图与评审的假设，不是受访者已表达的偏好；每个情绪词都要有图中可指认的依据。

先列关键维度及其组合，再检查主关系相同的图片是否仍传达相近感受。材料不同本身不否决；不同材料叠加色彩、比例、表面和细节的不协调变化，可能使两件产品设计情绪相差过大。多个维度也不必逐项相同，只要变化彼此协调，仍指向同一整体感受。

不得按“不一致维度的个数”自动判退。逐图指出哪些组合拉偏情绪、影响是否能在成板尺寸下直接看见；用对照图复核，不靠形容词兜底。

“握手维度越多越好”落实为更多相互独立、图中可见且共同指向同一情绪的证据，不把“圆润／柔和／没尖角”重复计数。核心关系必须成立；次要关系允许相容变化。局部边缘稍锐、功能圆件或有限光哑差异是否可留，要看它的面积、位置、对比和形体角色；不能见到差异就淘汰，也不能让相反的主形态靠多项弱共性补偿。

风格假设须明确哪些可见关系共同支撑这组、哪些差异可容纳、哪些差异会拉偏整体感受。逐图对照最能表达该语言的原图，再检查整板中差异最大的一对。A与B相似、B与C相似，不代表A与C属于同一风格；不得靠中间图把两种不同情绪串成一组。只有一个共同元素、其余维度分散时，保留为元素素材，不能升为风格板。

## 选图与排除

1. 原图中必须看得到必要证据；不能借文章标题补证。材质和工艺未核实时使用“金属外观、织物外观、细哑光”等描述。
2. 不同材料可以同板，但主次、搭配和整体设计情绪要协调。仅轮廓都圆润仍不足以通过；同时检查色彩、比例、表面与细节差异是否叠加成明显不同的整体感受，不把材料差异单独作为否决条件。
   配色须记录色相搭配、饱和度与明度范围、颜色面积主次及落点、拼接／渐变／点缀方式；“都是多彩”不构成同组证据。纹理须看尺度、密度、反差、覆盖与结构的关系；“都有粗颗粒”不构成总体风格证据。具体用法见[多维关系与配色收敛](references/multidimensional-style-review.md)。
3. 局部图必须保留设计关系。布样、木纹或纯色面若只剩材料词、不能体现所选关系，不足以支撑该家族；表面方向本身就是主题时可例外。
4. 反射可作为可见表面处理的证据；灯光造成的亮暗不能单独证明CMF一致。透明性需要后层、透过纹理或透明边缘等证据。
5. 记录预计展示介质、成板展示宽度及审阅倍率，在该尺寸复核每张图。展示条件未定时按当前输出的100%尺寸初审，标注实际访谈尺寸未校准。特征过小、遮挡或取景丢失关键连接时，调整取景、补原图或替换；不能用文字说明将其判为通过。

逐图记录“支持关系的可见位置、会抢主题的因素、保留／调整／替换／待定及原因”。细则见[选图与整板复核](references/selection-and-review.md)。

## 组板与复核

当前项目每板至少8张已有图库或已授权补充来源的原图；实拍或概念渲染性质分别标注，不把来源图都声称为实物照片。不得为补足数量加入弱匹配图。参考板自身张数或布局不改变当前数量政策；背景、同一原图的多个裁切和参考图不计入新候选数。正式成板同一已知文章或项目最多一张；未知项目身份如实标注。

先用实际候选试一组，检查三件事：每张是否都直接支持所声明层级的设计语言／主关系；多维组合后整板是否传达相近的设计情绪；拿掉标题后是否能和相邻方向区分。题材丰富、排版整齐、数量满足都不能代替这三项。总体风格任务另记跨品类支持及边界，允许元素证据成立而风格判断失败。

设计启发还须看得到可迁移的处理：边界、邻接、色彩落点、表面组织或形体构造。若只剩一组材料样片，即使一致，也不代表访谈刺激有效。无需规定全貌图与细节图比例，以所选关系的可见性决定。

优先核对容易混淆的方向：G5浅暖主体／G6深色主体；G8局部强色／G10有色主体；G2镜面外观／G4有色光亮壳体；G11光谱色／G13透光层。参考板间允许图片重用；区别看整体主关系，而非强制每张互斥。

## 证据与执行边界

观察事实、AI解释、用户反馈、未核实材料事实分别记录。作者自审不等于设计师认可；数量、链接和文件哈希检查不等于视觉通过。

保留原素材、来源ID、取景范围与成板版本。规则改变后重审受影响图片，不改原预期凑通过。素材不足时报告可成立的组数与缺口，不通过降低一致性补满。

当前用户明确要求“这些图，别重绘”。本项目选图与成板使用可追溯的原图库或已授权补充来源图片，做裁切、等比缩放、拼贴与板内文字；不调用生成模型重画产品、改色、补纹理或补部件。旧生成成板仅能作反馈案例，不能充当原图素材或证明原素材的风格成立。未来若明确另做生成概念，单独标识，不混入原图访谈板。

总体风格输出同时保留纯图片审阅／访谈版与带主题说明、来源标签的设计师沟通版。解释文字不得成为纯图片版成立的前提；最终呈现质量按第三张参考的主次、取景、对齐、留白和表面细节清晰度审阅，不要求机械复制其背景或叠压方式。

用户索要原文件或交同事改版时，按[原文件交付](references/source-handoff.md)提供指定版本的高清板、完整原图、可编辑排版及来源／用研绑定。原来没有PPT等设计文件时，明确区分原始输出与本轮补建的可编辑文件，不能把整板截图放入PPT后声称图文分别可编辑。

简单视觉试验可以直接做，但不能声称已完成H01／H2正式流程。接正式流程时保留上游选择、负向与未决项，按[上游衔接](references/upstream-protocol.md)输出可追溯结果。未经用户授权，不额外采图、调用付费服务、发布或扩展制作。
