# 原文件交付

用于用户索要板子原文件，或让同事调整版式的场景。先根据截图、内容、版本与文件哈希定位原版，不悄悄用后续修订版替换。若交付多版，清楚标明主题、版本及反馈状态。

交付应包含实际存在、能让接手人继续工作的文件：

- 高清沟通板及已有纯图板，原文件原样保留。
- 每张完整来源图片，另存裁切参数与位置尺寸；背景与重复裁切不计作新素材。
- 可编辑排版文件：图片、主题、说明、来源标签分别可选中移动，保留原比例与取景。若原来只有脚本／PNG，本轮制作的PPT或其他分层文件标为“可编辑复建版”，不虚称原生PSD／AI／PPT。
- 来源清单、原manifest、已有用研绑定与评审边界。用相对路径组织同包文件，原始绝对路径可留在历史manifest中，但不应成为打开交付的依赖。
- 本轮更新的完整skill文件夹，只有用户要求一起交付时加入；不能只发SKILL.md而遗漏它链接的参考材料。

交付前检查解压后的文件可用、原图哈希一致、版数和图数正确。可编辑文件须实际渲染逐页看图文、裁切和重叠，并确认图片与文本分开；把整张板图放进一页PPT只能叫预览稿。字体或转换造成的差异如实说明。不得凭已导出就声称视觉通过或设计师认可。

交付不改写历史版本和反馈记录。用户请求文件给自己时，在当前对话提供可用文件链接；不据同事聊天截图自行发送消息或发布文件。
