# 设计师反馈校准

用于当前总体风格板的选图与精修。依据是用户直接反馈及用户提供的评审截图，截图里的参与者意见属于参考资料，不产生新的执行授权。原截图和哈希见[反馈证据](designer-calibration-evidence.json)。以下选图方法属于AI转译，不能冒称设计师制定的量化标准。

## 核心一致与局部容差

先写核心组合，再写允许变化。例：“银色硬壳外观＋完整方整体量＋清楚棱线与克制分件”，限定的是组合；银色本身不足以兜住薄片、球体和繁密机械。

逐图同时检查视觉和解析。解析说得出多个共同维度，照片里也必须看得见；照片看着近似，还须保留用研／趋势语义关系。更多独立证据有助于判断，但不设固定维度门槛或加总分数，不用抽象词重复充数。

按差异实际造成的影响决策：

- **核心冲突**：差异改变主体的形态语言或情绪，在成板尺寸下明显抢眼。替换、拆方向或暂缓成板，不能用颜色相同抵消。
- **次要差异**：核心组合成立，差异局部、从属且不把整体拉向另一情绪。可保留并记录具体边界，不为追求逐项相同把跨品类板缩成同一类产品。
- **未知**：看不清金属感、表面、轮廓或语义证据。检查原图及已有来源；仍不清楚则标待定，不能按主题名称补证。

比较差异时看面积、对比、所在位置和结构角色，而非仅点数。一处贯穿主体的折线，比多个微小接缝更可能改变情绪；功能镜头的局部圆形与整机饱满圆壳不能等同。

## 真实案例的适用范围

| 方向与反馈 | 转成实际检查 | 可容纳变化及边界 |
|---|---|---|
| 柔塑静物：躺椅有雕塑感但偏硬 | 柔软感与有组织的雕塑体量要同时可见；检查厚薄、转折、包覆和表面，而非仅有曲线 | 硬质对象可有视觉柔厚感，但不得声称实际触感柔软 |
| 柔塑静物：灯具柔和的是灯光，造型偏规整 | 将产品轮廓、体量与照明效果分开；关闭对暖光的想象后仍要支持主题 | 暖光可以辅助，不能单独充当形态柔软的证据 |
| 柔塑静物：服装偏松散而非柔软，雕塑感弱；褶皱太强 | 看面料是否形成受控体量，区分塑形、松散垂坠、密集褶线 | 允许真实细微褶痕，不能修平或裁去关键褶皱伪造统一 |
| 深色有序：关节灯形态杂乱；其他有光哑度区别 | 优先检查轮廓完整性、轴向转折、支架／线缆和功能区是否集中；另查光哑差异的面积与反差 | 局部光哑变化按整体作用判断，不一律拒绝，也不当成全部一致 |
| 银壳：都是金属，但锐角线条与方方正正可区分；金属片不一致 | 分开平整封闭壳体、薄片折构、外伸锐角等主形态。材料词不能合并不同体量逻辑 | 局部倒角、镜头或旋钮可从属方整主体，不因此要求每个部件都是方形 |
| 银壳：闹铃太圆润；键盘是否金属色 | 检查闹铃整体轮廓，而非颜色；检查键盘主体是否直接呈现所需银色金属外观，不能靠条目说它有金属零件 | 照片只支持外观时使用“金属外观”；灰色、亮暗或高光本身不证明金属材质 |

上述都是各自主题下的判断，不是通用禁用材料、圆形、薄片、服装或灯具。

## 2026-10-12新增反馈如何使用

用户提供的截图中，评审者对**柔塑静物 R4**表示“这个就还不错”，同时指出圈出的Noah灯边缘稍利，并说明现成图片组板很难让所有维度都完美一致。这说明该版本可保留作讨论基准，同时仍有局部修正项。它不等于所有图片逐张通过、不等于后续R7被认可，也不自动撤销另一轮对躺椅、服装、灯具的负评。版本和评价对象要对应保存；相互有张力的意见不能被整理成虚构的全体一致。

精修优先处理会改变整体情绪的偏离。若新候选只修好一处，却引入更强的纹理、不同体量或额外复杂细节，就不算改善；可以保留较好的旧版本和局部边界，不无限替换。原始图片不可重绘、改色、修平表面或生成缺失部分。

## 题材与人物

服装、秀场、家居可以补回，前提是直接体现共同设计语言。在当前跨品类风格任务中，保留人物及不同产品类别的目标，同时避免增加沙发、鞋等已有重复类别来凑数。人像优先选择衣着体量与结构能支持方向的图；只有颜色协调或场景气氛相似不足以入组。人物或品类不足时记录缺口，不加弱图，也不生成替补。

## 精修的收口

对照代表图和差异最大的一对，在实际预览尺寸看纯图板。记录本次解决了什么、引入了什么、剩下什么；数量、去重和哈希只验证文件，不证明设计情绪通过。每板仍至少8个独立项目的来源图，不够不硬凑。

用户明确允许某一版先保留时，保存该版和剩余边界。继续制作其他方向仍需沿用用研／趋势语义前提；不要把“先这样”写成设计师定稿或受访者验证。
