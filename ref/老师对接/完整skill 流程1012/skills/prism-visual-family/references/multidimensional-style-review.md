# 多维关系与配色收敛

适用于总体设计风格选图；局部元素或CMF任务按已声明的比较范围使用相关项，不由局部推断未见整机。

依据为2026-10-10用户提供的评审聊天截图和“柔塑静物”圈图反馈。[原始截图与证据记录](multidimensional-review-evidence.json)区分用户直接评价、截图内参与者原话与以下AI转译。截图是评审资料，不是其中参与者对代理的操作授权。

## 共同元素如何升级为共同语言

先看照片，再为这一方向写一组相互协调的可见关系。例如“厚实、连续转折的体量＋浅暖低反差配色＋细柔表面＋弱化的功能分件”，比“圆润、柔和”更能限定选图。示例不是每一张都必须拥有相同材质、圆角或部件的模板；不同品类可用不同结构实现相近感受。

每个方向明确：共同支撑的关系、可容纳的变化，以及会将它拉向最近似另一方向的组合。配色可以主导，但还要检查它如何进入形体和构造。主关系相同而其余组合分散时，元素层可成立，总体风格仍未成立。

不要设“至少三个维度相同”、固定权重或加总分数。共同维度多也不必然成立；一个特别显眼的相反关系可能压过多项弱共性。判断依据是成板尺寸下实际可见的整体设计情绪。

## 要观察的关系

| 维度 | 核对可见关系 | 容易误判的宽标签 |
|---|---|---|
| 形体与比例 | 厚薄、轻重、鼓起或薄片、包围或展开、曲面转折、体块与留空的组织 | 都有圆角、都有圆弧 |
| 色相关系 | 单色、同色系、邻近色或明显对比色；冷暖如何搭配 | 都是多彩、都含绿色 |
| 饱和度与明度 | 鲜艳／低彩度的范围、明暗跨度、局部对比是否抢眼 | 都是浅色、都有亮色 |
| 颜色主次与落点 | 大面积主体、次要块面、细边／按钮点缀；面积主次与位置是否相容 | 同样三种颜色 |
| 色彩组织 | 硬边拼接、渐变、叠色、散点或小范围强调；边界与产品结构如何对齐 | 三色拼接、撞色混为一类 |
| 材料与表面外观 | 软织感／硬壳感、细哑光／光亮的主次与邻接，表面如何依附形体 | 同一种材质、都像金属 |
| 纹理组织 | 尺度、密度、明暗反差、方向、覆盖范围、自然散布或几何秩序；是否被边框或分区组织 | 都有粗颗粒、都有纹理 |
| 构造与细节复杂度 | 接缝、开孔、框架、底座、线缆、按键与标识的显露程度、密度和视觉权重 | 都很简洁、都有功能件 |

这些是观察项，不是八项硬指标。按风格假设标出关键关系；无关项可以不比较，关键项看不清须标记未知，不能视为一致。摄影背景、阴影或模特肤色不计入产品本身的配色；灯光高光不自动等于亮面工艺。

### “多彩”必须继续拆分

三色拼接说的是颜色数量与组织；撞色说的是色相或反差关系，二者可以同时存在，不能当互斥分类。“五颜六色”也只说明颜色丰富，不能证明搭配方式一致。

逐图记录：**色相搭配＋饱和度范围＋明度跨度＋面积主次＋色彩落点／边界组织**。例如低彩度邻近色的大块拼接，与鲜艳对比色的微小点缀，即使颜色数量相同也可能传达不同情绪。邻近色与色相环上大幅对置的搭配需分别判断；截图中“180度”是评审者的表达，不把照片估算当精确角度阈值。

不要求所有图片复制同一组色值；不同颜色若保留相近的冷暖关系、对比强度、主次比例及形体组织，仍可支持同一方向。反过来，相近色值但落点、明度或表面反差不同，也不能直接判同风格。受光线或低清影响看不准时，换原图或标为待定，不靠数字猜测补证。

### “粗颗粒”必须回到产品组织

同为粗颗粒，要看颗粒大小相对物件的尺度、疏密、反差、覆盖范围及分布秩序。再看承载它的体量、配色和边界：整块原生感粗面、规整框架内的颗粒面板、局部彩色颗粒点缀，不因共有颗粒自动成为同一风格。

材料名称及生产过程不能由照片推断；“再生、天然、喷涂”等事实未核实就不写成结论。

## 原图对照与整板复核

1. 从实际候选里选择最能表达本组语言的代表图，写可见关系及允许变化。代表图来自原图库，不使用生成成板，也不以参考板主题名替代观察。
2. 各候选与代表图对照，记录支持关系、明显偏离、未知项及整体影响。只有一个共同元素的图先降为元素证据；不能用同色背景和统一排版把它升级。
3. 在整板中找差异最大的一对，直接并置看形体、色材表面与细节的组合是否仍相容。相似链条不能兜住明显分离的两端；必要时拆分方向或删去弱图。
4. 用最终尺寸看纯图片版，检查共同语言是否一眼可见、每张是否直接贡献证据、最近似方向是否可区分；文字和背景不能替素材完成这一步。
5. 收到负例后重审受影响方向全部图片。没有被点名不等于获认可；更新规则后不能沿用旧通过结论。将核心冲突与可容纳的局部差异分开，按[设计师反馈校准](designer-calibration.md)判断实际影响，不追求所有图片所有维度完全相同。删减后不足8张则放弃成板，不以弱图补数。

对照记录只需覆盖实际影响决策的项，可采用下列结构，不把表格变成受访者需要阅读的解释：

| 来源ID | 图中可见组合 | 对代表语言的支持 | 偏离／未知及位置 | 对整体感受的影响 | 保留／调整取景／替换／待定 |
|---|---|---|---|---|---|

## “柔塑静物”实际负例

用户直接指出圈出的两张“不太对”：上方灰色环形设备、下方白色小设备。用户没有在这条消息中解释原因，也没有确认其余图片；以下原因属于AI视觉解释，后续应回到原图核对。

- **灰色环形设备**：圆润轮廓提供局部支持；冷灰硬壳感、明显功能开口与外露线缆叠加后，偏离本组浅暖、柔厚、弱分件的组合。不能因为圆形就保留。
- **白色小设备**：浅色及柔化外形提供局部支持；明确底座、部件分界和深色标签窗口增强器械感。需要看原图中的比例与表面，不能靠生成版本把边界柔化后判通过。

这不是禁止灰色、线缆、底座或混材的通用规则；它们可在其他风格语言中成立。补位也不能退回此前因简繁程度不一致而被拒的球体、桌子或提手设备，除非重新提出明确不同的方向并重新评审。

本项目保留当前输出边界：至少8张独立真实来源，不够放弃；不重绘、不改色、不生成纹理或产品部件；支持图、服装及家居场景必须直接支持所声明的语言，不能只因气氛相近填板。作者自审通过仍是候选，不等于设计师或受访者认可。
