# 棱镜｜方向选择


消费完整H01候选、逐候选审阅、原话及来源范围；选向依据是共同设计原则、支持边界和研究价值。库内文章规模、支持人数和视觉素材容量分列，不能合成未经验证的商业高潜分。

沿用当前已确认方向。新选择由用户/设计师作出，或在本次明确AI代选授权下完成并记录actor_kind；不得把AI选择写成人类确认。无需对已经授权的继续工作再次询问。

方向数量随任务与证据决定。自动Top N仅在用户要求时登记排序规则和N，重排保留原版本；不继承历史Top5。保留所有未选、否定、未决与跨产品迁移限制。

完整交接selection、H01 refs、原研究单元与趋势父簇、negative_audit、deferred_obligations。正式模式用H01现有select协议，不用本地自造confirmed字段绕过。语义选向只给探索依据，不给银色、材质、价位或人群偏好背书。
