# 棱镜｜扩充候选与选图


从选中方向的成员文章展开图片引用，保留article_id、原父簇、原URL、图序、来源组、已知项目/系列、SHA与像素。链接去重、字节去重、项目去重分别做；相同字节仍保留多方向映射。

候选阶段保留同文多视角。最终同一已知文章/项目最多一张；未知身份保留未知，不能用不同URL证明独立项目。原图库和已获授权的外部补图均可用，补图单列visual_extension及来源/语义待核状态，不改写原父簇。

秀场、服装、家居场景不按类别先清空。它们能支持完整设计语言时有价值；只靠同色、穿着情绪或背景灯光相似不够。人物与产品的柔软、雕塑、规整、锋利等主形态必须一起核对。品类丰富不是加入弱图的理由。

按主方向和子关系分批查看缩略导航，再查看入选原图及最不一致组合。记录总链接、可读图片、去重SHA、去重项目、实际看过原图/缩略图数、各方向覆盖与失败。看过480张不代表看过8000+，不能据小样宣布图库上限。

只使用可见观察和可回指解析；DNA缺失不自动删除好素材，但要保留未解析状态。原图复核反证写入补充观察，不篡改冻结DNA。关键词召回/算法分组仅供导航。

辅助工具：`assets.py --help`登记原图，未给`--download`不联网；`recall.py --help`仅字面召回。工具得分不是语义或视觉通过。最新图数、来源与证据字段见[风格成板合同](../prism_skill_support/references/style-board-contract.md)。
