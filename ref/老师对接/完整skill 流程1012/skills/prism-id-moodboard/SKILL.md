# 棱镜｜ID与总体风格


先读`prism-visual-family`的总体风格和多维规则。输入选中语义方向、完整research-binding、风格假设及实际候选。DNA簇是可选导航，不是唯一入场条件或最终答案。

比较主导轮廓、体块、比例、曲面转折、部件边界、构造层级、线条密度，再检查色材及表面组织是否共同指向相近情绪。局部圆角、银色或轮子的形状不足以证明整体相同。

每组写核心关系、可容纳变化和会拉偏的主形态；逐图指出实际位置，检查差异最大的一对，防止A像B、B像C但A与C情绪不同。跨品类用于检验语言成立，不能为配额加弱图；避免全是沙发或同系列变体。

至少8张独立来源原图，不足保存为研究候选，不能叫合格访谈板。记录原图、裁切、来源、语义联系、实际观察、未决和排除理由。产品启发指向可见的形体/边界/构造决策，工程可行性单列未核。

固定ID H2适配器仅用于原生协议兼容，未运行就写not_executed。总体风格视觉结果不能沿用旧H2、DNA或机器PASS背书。
