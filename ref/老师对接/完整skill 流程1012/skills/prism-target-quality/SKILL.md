# 棱镜｜当前目标品质


检查已绑定对象的清晰度、遮挡、表面与结构证据、背景竞争、成板尺寸可读性。不能继承同图另一对象的品质结论；单张精美不证明同板情绪一致。

只将照片可见的材料外观、表面处理、边界和细节作为依据。不从塑料/金属类别直接推断高低端，不断言真实触感、价格或工艺；灯光柔和不等于产品形态柔软，灰色不等于金属。

需要时换同源高分辨率图或调整裁切再审。当前原图约束不允许生成补细节、调色、重绘、磨皮/纹理替换；不以AI增强造出材料证据。

品质不合、风格冲突、DNA未知、来源未核分别记录；不要静默缩小冻结候选分母。正式旧Quality流程可用`native_api.py`白名单，但结果只适用其实际目标、规则与输入。
