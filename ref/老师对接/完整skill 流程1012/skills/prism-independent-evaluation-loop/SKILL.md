# 棱镜｜有界复核与反馈更新


冻结输入、规则和实际模型身份；按最新任务核查影响范围。工程检查证明文件、身份与接口，语义审阅证明引用解释范围，实际看图证明可见关系；三者不互相冒充。

评估用研反例：品牌名不等于偏好、举例不等于喜欢、同人多记录不加人数、not/but/too及原对象不丢。评估风格反例：软灯光不等于软形态、松散服装不等于柔软雕塑、同金属不等于同体块、粗颗粒/多彩不能单维成组。

记录总库与实际覆盖；新图、复用DNA、失败、未决、原图查看与缩略导航分别计数。既有反馈案例是校准数据，不能当独立盲测准确率。

需要独立上下文时遵从当前任务的委派权限；没有就做作者自审并标明。独立评审不得预填作者结论。真实失败要保留，最多三轮围绕同一问题定点修正；不得换ID重置预算或降标准凑通过。

新反馈只更新受影响规则/版本与案例，不全球撤销旧判断。不要恢复旧DINO、自动化或已停模型队列。迁移验证使用合成数据/已有离线结果，不发新付费请求。
