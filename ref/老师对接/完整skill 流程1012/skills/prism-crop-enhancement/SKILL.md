# 棱镜｜原图裁切与编排


先确定每张图需要证明的对象及设计关系，再定取景。保留支持关系的曲面转折、相邻界面及厚度；不要用裁切藏掉会改变主题的产品主体。

当前总体风格版式参照设计师第三张“男模/原质新生”的主次、留白、叠放、取景与精细度；不是固定5×2。版式可有大小层级，统一对齐与间距，禁止拉伸或靠大面积装饰制造一致性。

当前使用原图、可逆ROI、等比缩放、图层拼贴及板内短说明。不生成重绘、不调色、不补纹理/部件、不把生成概念混入原图来源。需抠图时使用保留原像素的非生成蒙版并保存蒙版；不得删改产品细节来消除冲突。

同源备选可改善取景，但最终来源去重。每次替换或ROI变化重新看成板，与原图并排检查。默认同时输出纯图片访谈版及带主题短说明的沟通版；文案压在板内，不能遮挡核心证据。

`render_style_board.py --board board.v4.json --out rendered`按手工layout生成自包含HTML双版本；只显示真实原图，不给视觉通过。高清PNG或可编辑PPT可用当前环境工具导出，需实际渲染核对。无原始设计文件时明确标为复建。
