# 棱镜｜CMF与总体风格


先读`prism-visual-family`。只在同一表面或同物件真实邻接界面上比较，不拼合不同物件的色彩、光泽和纹理为一个不存在的对象。

配色检查色相关系、明度/饱和度范围、面积主次、落点、拼接/渐变/点缀方式。邻近色与对比色、三色拼接与杂色不是同一关系。粗颗粒检查颗粒尺度、密度、反差、分布、覆盖及与形体的关系。

颜色、材料外观、表面处理可单独成为局部CMF议题，但总体风格还要看形体/比例/构造及设计情绪。光泽应有表面证据，光照造成的亮暗不单独算CMF；灰色键盘不能直接记成金属。

材料不同本身不否决；多个显著差异叠加改变设计情绪时才应拆组。反之不能凭都是金属，把厚实包覆方壳、折叠薄片和尖锐构架合在一组。局部功能圆件不等于整个产品圆润。

保留语义研究绑定，至少8张原图和来源去重。不足不凑；特征需在实际成板尺寸可見。标题和材料文案不能救弱图。正式原生CMF H2单独记录是否执行。
