# 原文件与技能交付合同 4.3

按用户指定版本交付。原始高清板保持原字节，编辑版若后补则标“可编辑复建”；图、文字独立对象可移动，不能把整板截图塞入PPT充原文件。纯图版与沟通版分开，沟通文字位于板内。

原文件目录至少包含originals、视窗/蒙版（实际用到时）、layout参数、来源CSV/JSON、research-binding、review、说明及完整性哈希。外部补图保留URL、项目身份和语义状态。移机采用相对资源，原绝对FileRef保留历史并另建新映射。

技能方法包包含18个SKILL、全部相对依赖、真实需要的运行脚本/提示/字典/模式说明、合成测试与校准图。完整原图库与私有访谈是数据输入，不是默认方法依赖。缺输入在开始时报告，不能说安装即复现全部现有研究。

先做文件/引用/语法检查，离线跑核心回放和边界案例，再移到中文空格路径解压验证安装及相对定位。技术测试结论与新语义/视觉效果分开。发布新包不覆盖历史包。

发送给同事、群聊、邮箱或公开站点需用户明确指令；整理本地可下载ZIP本身不触发外发。使用说明写成同事可按步骤执行的短入口。
