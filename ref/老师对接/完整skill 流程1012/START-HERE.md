## 第一次使用

1. 完整解压，保留skills中的18个技能目录和prism_skill_support，共19个目录，不能只复制SKILL.md。
2. Python 3.12+；已有依赖可直接离线校验，缺少时在自己选定的Python环境安装requirements.txt。真实推理使用自己的助手/账号配置；本包没有账号或费用授权。
3. 下列命令从包根运行。先检查和预览，再安装；目标已有同名目录时工具拒绝覆盖，按本次授权先备份并明确替换范围。

```text
python -B -X utf8 tools/verify_bundle.py
python -B -X utf8 tools/doctor.py
python -m pip install -r requirements.txt
python -B -X utf8 tools/run_checks.py --out "自己的工作目录/棱镜离线验证" --native
python -B -X utf8 tools/demo_style_contract.py --out "自己的工作目录/合成合同演示"
python -B -X utf8 tools/install.py --dest "目标项目/.agents/skills"
python -B -X utf8 tools/install.py --dest "目标项目/.agents/skills" --apply
```

依赖已满足时跳过pip install。这些离线检查不调用模型、不采图、不发布；合成演示不是真实设计板。字体用于浏览器显示，可采用本机Arial、微软雅黑或合适替代，替代字体需重新看排版。
