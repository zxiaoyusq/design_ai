# 棱镜｜广候选池与素材计划

读取 [素材与目标合同](../prism_skill_support/references/contracts.md) 及 [选材前置合同](../prism_skill_support/references/material-contract.md)。输入selection和已定视觉家族，输出metadata-pool、原图manifest、material-plan及冻结的DNA候选池。

从已选趋势主题成员出发，必要时使用有明确设计关系依据的跨品类参考，分别标原主题成员与扩展参考。字面召回器recall.py只帮找候选，不证明图片适合。不从旧成板图反向决定所有可选方向。

维护article_id、source_group_id、原始URL、图序、SHA、像素和可核实project/series身份。同一文章图组可保留多个视角供判断，最后同一来源/已识别同一项目每板最多一张。未知项目关系保留未知，不能把不同URL就称独立来源。

实际看预览和需要的原图，逐张说明：哪个对象、哪个表面/整体状态、主关系是否可见、第二强信号是否干扰、建议ROI、保留/裁切/增强/补资料/不适用及理由。可以使用画面中的非主角，但必须重新绑定和审品质。校准板不得混进候选。

最终10来张来自更广候选；候选规模由独立项目容量、异质性和预算确定，不能默认只解析10–12张。覆盖比较实验应冻结全部有界候选，记录未完成和失败；普通节省模式的任何前置排除也必须预先声明。

下载器assets.py acquire默认只读本地清单，显式--download才读取已列URL；不自动爬取新库。gallery只做原图导航，不发模型。material_plan.py只检查合同与证据身份，不产生视觉PASS。

像素不足先考虑同来源更清楚原图、合适裁切或独立展示增强；无法看清真实关系则保留待证，不把“解析失败”“不典型”“图不够清楚”合成一个标签。候选不足反馈到上游一次明确决策，不无限回找。
