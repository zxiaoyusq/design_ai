# 棱镜｜独立测试与定点改良

读取 [评估与复用合同](../prism_skill_support/references/evaluation-contract.md)。输入新交付、作者明确自评范围、版本/依赖、实际输入输出、既有判标；输出冻结索引、独立结果、问题卡和复验状态。

先区分新代码/新规则/新语义输入与仅增加说明。无新合格范围就不重跑；整体partial仅消费其中明确可用的范围。作者测试数、离线重放和真实视觉效果分开。

冻结源码、真实依赖、原图/原话、prompt、schema、原答复和哈希。测试覆盖受影响模块及必要关联回归；身份或语义变了先检查判标，不修改预期凑通过。未知费用/用量不当0。

具体失败先写issue_id、版本、最小输入、预期/实际、证据、责任边界、建议和复验条件。当前任务自己可修本地有权部分；跨聊天消息和owner改代码需当前授权，不因安装技能自动获得权力。不要覆盖其他人的共享工作。

每个同一问题最多三轮定点修复；仍失败记录已到限，明确需方法变更或用户决策。不能换issue名称无限循环，不能因一处阻断把全部目标标complete；独立工作可继续。

语义、DNA结构可消费、字段视觉正确、目标品质、整板一致、数量、用户认可分别验收。完整216字典不等于每张都应填216值。指标报告原图分母、复用、新请求、定点确认、共享修复的去重口径。

同图同规则同有效输入复用DNA；当前目标/视窗变化只重做受影响绑定、品质、分组或板审。已完成的重放不计新推理。调度优先短任务卡、明确输入输出与就绪依赖，准备与修改顺序执行；没有明确授权不创建任务或启动多agent。

本技能不会恢复历史heartbeat、重置卡、付费批次或发布。用户要求持续跟进时再按当前工具配置调度，并在无变化时保持安静。
