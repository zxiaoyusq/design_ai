# 棱镜｜整板独立审阅

输入冻结brief、实际渲染整板、逐张原图/实际视窗、候选选择记录、来源和原负向；输出独立board-review与分维度结论。读取 [整板审阅合同](../prism_skill_support/references/review-contract.md)。

审阅者实际看整板及图像，不只读作者理由或统计。独立上下文使用相同事先标准，不附加未预告的审美限制，也不因作者写了PASS而通过。AI独立上下文不是人类金标。

逐张检查当前对象和范围、主关系、第二强信号、允许变化、载体边界及交付尺度可读性；再看组合是否形成一致而不机械重复的家族。ID核整体，CMF核局部，不能拿整照片要求评价裁片范围。

来源独立性、数量和哈希由真实台账校验，不要求看图模型凭空验证。语义、视觉、数量、来源/证据、用户反馈分别记录；数量满10不掩盖离群项，数量缺口也不抹掉有价值的视觉反馈。

具体失败指出哪张、哪个区域、哪条已冻结条件、应该裁切/补图/增强/替换的原因。优先复用候选池定点修正；保留原失败、旧图和输入哈希。N111被花色干扰、换成N080后通过是一个案例，不是固定替换策略。

本地review_gate.py只核身份、格式和声明间一致性，不会自动看图或颁发审美PASS。正式native H2还须调用原prepare_board_review/accept_board_review；独立单板视觉试验没有跑原生门时明确写未执行，不升格为全链路合格。

问题最多三轮定点修订；到限交 `$prism-independent-evaluation-loop` 留证据并明确下一决策。完成后交付当前版本及旧失败，不覆盖历史。
