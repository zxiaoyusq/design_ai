# 棱镜｜取景与展示增强

读取 [选材前置合同](../prism_skill_support/references/material-contract.md) 的“处理分支”。输入已选目标、ROI、原图SHA/像素、当前视觉家族和显示用途；输出实际视窗、处理台账、原图/展示版关系及复核结果。

先确定最合适的取景，不能为增加像素而把无关内容放回来。ID保留当前整体关系；CMF保留比较表面与必要载体边界。使用render_board.py的可逆HTML/CSS视窗展示时，原图字节不变；截图是实际显示证据，不是新增原始分辨率。

三种问题分开：目标错误→重选并重绑；取景不当→改ROI并重看；原图细节可读但交付像素不足→优先更清楚同源原图，或在授权内做单独展示增强。缺少真实细节证据→待证，不能靠生成纹理宣称正确。不要因像素不足直接断言不典型。

若需要AI后期增强，使用当前环境明确提供的图像编辑工具并遵守其能力和授权；先看原图。约束对象、轮廓、纹理方向、数量、接缝、颜色和材质外观保持一致，不新增字样、饰件或工艺。没有可用增强能力就交原尺寸及待办，不伪造高清结果。

保存 original_ref、comparison_view_ref、display_variant_ref、方法、工具、实际参数/提示词、实际回执和变更审阅。增强图必须标展示用途，不能覆盖原图、回写DNA、替代原始品质证据或进入盲评原图对照。

另一个真实阅读上下文比较原图、视窗和增强版：对象一致、裁切没有藏掉反证、关键结构未改、显示确实改善。只因输出像素更大不算质量改善。失败仅修这一目标，不重跑全板全部DNA。
