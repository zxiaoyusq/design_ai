# 独立评估、复用与指标

## 三类成功率

1. 传输/结构成功：调用返回，可由原schema和decoder接受。它不保证图像内容正确。
2. 已知范围可消费：同SHA、同版本与原记录绑定合法，下游可以使用已知项；partial中的未知仍未知。
3. 视觉正确：对实际图像和适用字段有独立标注/评审证据。没有人类金标准不能用前两者声称全字段准确率。

R5的第一次主解析＋必要困难项定点确认是一套既有设计。第二逻辑请求不是整套算法失败。2026-10-03的500张新图中486张最终可消费已知范围；422张用了第二逻辑确认/修复；64张仅一个请求就有可用结果；14张最终未过。97.2%不是视觉准确率，12.8%也不是整套R5算法成功率。完整216字典不要求每图填216个值。

## 台账

记录文章数、图片关联位、成功获取位、去重SHA原图数、独立项目数、冻结候选数、DNA复用/新输入、主判/确认/片段修复实际请求、品质审阅、裁片/增强、最终图片位和独立来源。共享批次的实际CLI请求只计一次，同时注明影响了多少原图；逻辑按图尝试数不等于HTTP/CLI请求数。

usage含input、cached_input、output时，缓存输入是输入的子集，不能再加一次。unknown不当0，token不冒充账单美元。真实AI推理、程序重放、合成夹具、参考例子、用户反馈分别计数。

## 增量与失败

复用键至少包括阶段、算法版本/源码哈希、有效输入哈希、模型策略、当前target/view和必要父契约。只增加报告说明不重跑；模型、语义、目标或图字节变化则复验相关范围。已有整板的某一图变了，要复验该图及组合效果，不默认重跑所有DNA。

问题卡包含最小输入ref、原图/原答复ref、expected/actual、版本、责任方、建议和复验条件。三轮以同一具体问题为单位，换编号不能重置预算。到限保留状态并提出方法决策，不自动给PASS或结束整个目标。

2026-10-03 30/100比较：582独立原图、500新＋82复用、568有已知范围，两个档位原生完整整板各0/6。之后线性槽纹单板经一次替换AI视觉PASS，只证明该比较范围。二者不能合并成“六项算法终于全合格”。
