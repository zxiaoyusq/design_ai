当前声明状态与可见范围解释补充政策（ID / CMF）
版本：declared-visible-scope-policy-v1.1.0

本政策只解释选定 ID 或 CMF 目标的 coverage / target_verdict，不修改原目标、品质门槛或输出 schema。它不是放行指令，不预定 exact_target，更不预定 PASS。原图、target_digest、selected_scope、selection_reason、selected_scope_limits及原质量规则均保持。分别遵守overall_id和local_cmf用途，不互相替代。

S01｜先确定声明范围
评估范围由本次 selected_scope 及其选择语境确定，包括指定载体、明确的部位、当前声明状态和被请求的关系。selection_reason可说明为何选择这个视角；selected_scope_limits保留未知，不因写下一个未知就把未知对象变成新增检查目标。H01的宽泛主题、产品功能常识或评审者期望不得扩张本次目标。

S02｜整体不等于全状态或360度检查
当前图像中的整体 ID 参考，是被声明状态下的主要轮廓、比例和结构组织是否足以支撑本次目标。若只声明收拢外形/闭合外表面，就在该状态下判断；不得自动追加展开形态、内部、背面、打开方法、操作顺序或另一状态。只看到一个状态并非独立的 partial_target 理由。仍不能把看不见的其他状态说成已验证。

CMF 的 local_cmf 用途，评的是本次声明的可见表面、边缘或界面，不是全物体360度外观检查。“整件”可用来指定同一载体和所列部位，本身不自动变成“整件所有面均已验证”。若声明可见外表面与边缘，未请求的背侧/遮挡面未知应保留限制，不能仅因不见完整环形或背面而判目标范围不全。也不能把一个可见面的CMF性质推广到整件、背面或其他状态。

S03｜声明外未知只约束推论
对于未被请求的展开方式、内部结构或另一状态，原文保留到 coverage / quality limits，说明不能由本图推出这些事实；若当前被声明的目标实际清楚可读，不得仅凭这些声明外未知将 coverage 或目标对应复核降为 partial_target。exact_target也仅指声明范围，不表示该产品其他状态、功能或实物属性完整已知。

S04｜声明内遮挡仍须实判
真实遮挡、重叠、过曝、裁失、目标混淆或看不清指定关系仍有效。需指出它遮住了哪项已声明内容，以及是否实质阻碍本次主要形态/关系判断；若阻碍，维持 partial_target、uncertain或not_visible。若只是未被请求的小接口或不影响主要声明的细节，可记录限定并依据其余实际可见信息判断，不要求每个零件全可见。不能因为排除了“未见另一状态”的理由，就抹去真实遮挡或自动改为exact。

S05｜明确请求另一状态/内部时不适用豁免
若目标明确要求展开结构、内表面、内部接口、两个状态的对比或转换关系，这些就是声明内要求。原图没提供所需状态/部位/关系时必须保留范围缺口；不得用“当前状态政策”缩小用户或Root实际指定的目标。范围表述有歧义时保持待确认，不自行挑容易通过的解释。

同样，如果明确要求背面处理、全环连续性、所有面的统一表面处理或某一被遮挡的边缘/接口，那就不能以“只评可见面”排除这些要求。一个界面的两端都被指定时，不能只看见一端就声称完整关系成立；真实指定部位被截断/遮挡仍保持partial或pending。

S06｜不同判定不可互相替代
范围 exact_target 不等于品质 PASS；ID仍须有指定载体上具体、清楚、可复用的形态证据，CMF仍须有指定表面的具体色彩/表面/肌理/光学/分区关系，并分别满足原 quality 条件。目标范围正确但品质证据不足，仍可FAIL。品质可用也不等于与当前H2视觉组一致；群组可独立排除离群项，不能为了群组不匹配而虚构质量范围缺失。不能借其他对象或背景填目标，不能把局部CMF升级为整体ID。真实材质、内部构造、电气功能或反射率未知仍未知，不因使用名称或可见高光被当作已证实。

S07｜主判与原图目标复核使用同一范围
主判及 target-review 均须使用同一原始 target 和本政策版本。每个 partial/uncertain 理由要区分“声明内的实际缺口”与“声明外的推论限制”；两者可以同时存在，但不能混为一个自动否决。不得因为 disputed_evidence_ids 为空就自动exact，也不得只因 limits 非空就自动partial。已有所有真实限制仍完整承认和透传。

S08｜只用于显式的新实际评估
本政策不解释性改写任何历史 raw、target-review、scope_pending 或绑定hash。Root在新的有界实际调用中明确附加本政策，并保留其版本/字节hash与完整有效模型输入；得到新的原图证据与复核后才消费新结果。未知仍未知，旧pending保持旧pending，本政策不授予额外调用额度，不允许为凑数量放宽目标。
