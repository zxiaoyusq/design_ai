independent-evaluation-loop贯穿各环节，只验新增影响；不常驻循环消耗额度，不因安装而创建任务或调度。

一次只加载当前技能和需要的合同/代码。主任务持有总清单，工作项写清输入ref、责任范围、输出契约、预算与复验条件；没有明确允许的多agent授权时直接在当前任务顺序推进，独立工具读可并行。作者修复与验收不能互相覆盖产物。
