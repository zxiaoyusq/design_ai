# CMF表面细节第二次握手

先读 [组合输入输出合同](../prism_skill_support/references/contracts.md) 的“原生H2”和 [CMF接口](../prism_skill_support/references/native-api.md)。用cmf-reference-board-v4；使用过精确字节别名的记录全程走alias-cmf入口。

prepare要重放同一原图、原生质量bundle、R5已知局部位置、目标绑定与实际视窗。surface比较同一原位置；same_object_interface要求同一物件上的实际邻接关系。原图、位置、对象或来源不明时保留缺口，不通过重新命名绕过。

实际比较原图＋当前局部视窗，并使用当前设计师参考校准尺度。纹样、光感、分区和底面关系要可见；深色不等于高级，绿色/天然材料不等于自然图形，植物场景不等于表面纹样。整板配色可跨不同成员形成，不机械要求每件同样几种颜色。

分组提案完整记录成员/排除项、原观察证据、允许变化、主导混淆和负向适用范围。只比较当前声明的局部，不把未选的背面或品质父范围全部部件强塞进同一视窗；也不借切图隐去关键矛盾。

启用已有DNA省额度模式时遵守 [省额度选图政策](../prism_skill_support/references/budgeted-visual-selection.md)。本地关系预组和代表选择只是候选，不替代实际原图/ROI分组与独立整板判断；不为扩大组员池默认让供应商重读全库。继承累计入围与整板请求账本，改名、换批或修布局不重置上限；到限保留已形成内容和真实缺口，不凑数量或补PASS。

按预先登记的数量政策执行accept_grouping，然后对真实整板独立审阅。局部与整件混排导致尺度/视觉主次不一致时要修取景或排除离群项，不能仅靠都是黑色给PASS。未知真实材质、工艺、触感和反射率仍未知。

所有原负向按人、原对象、程度与当前范围分别处理，未来产品的阈值需求不是当前每张参考的默认缺陷。保留完整原记录，原生门仍拒绝时如实记协议/范围问题，不填伪义务索引凑通过。交付原分组、审阅、图像和限制给交付Skill。
