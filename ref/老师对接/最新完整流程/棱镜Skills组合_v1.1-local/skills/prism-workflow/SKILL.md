# 棱镜流程编排

先读 [组合输入输出合同](../prism_skill_support/references/contracts.md) 的“项目约定”和 [流程路由](references/routing.md)，按当前任务只加载需要的子Skill，不把13份说明一次性灌入每个模型。

先登记用户要解决的设计问题、资料范围、ID/CMF分支、候选数、图片目标数量、是否硬下限、模型及调用预算。用户给短指令即可；已有上下文能明确的不要重复询问。历史六卡是示例，不把6方向、3+3或至少10张固化成所有项目的要求。

趋势、H01方向及后续家族/卡片/报告的方向标题统一采用跨品类的审美机制表达，设计问题和共同定义同步保持这一层级。按轮廓、体量、细节布局、色彩或表面关系组织，不将衣服、手机、家具等品类或专属部位写进方向标题，也不按品类拆分同一机制。来源对象和场景保留在引用、变体和实际条件中；下游不能把通用方向重新命名成某一品类的设计方案。恢复历史结果时在新提案中改写展示与问题表达并保留原证据绑定。

无现成DNA时复用原实跑主干：两侧纯文字聚类→H01及实际选择→可见家族→原图导航/目标选择→用途品质→仅对选中图做R5→位置绑定/取景复核→分支H2→整板审阅与交付。准备好的相互独立方向可并行；依赖、审批和同一输出写入顺序执行。不要因缺旧DNA把新方向提前过滤。

已有提取DNA或当前任务启用省额度选图时，先读 [省额度选图政策](../prism_skill_support/references/budgeted-visual-selection.md)：先在方向内本地整理可见关系、去重与代表，不默认重读供应商；只对已授权的后续视觉环节执行真实模型判断。原图累计档位、详细ROI入围及每板审阅上限以该共享政策为准，继承已看图和真实调用账本，不按轮次重置。全库文本结束后的明确暂停必须保留；更新Skill、离线准备或编排恢复不解除暂停。

选择由真实用户完成，或基于本次明确授权代选并记录user_delegated_ai；历史代选权限不随本包转移。缺授权只完成可审阅准备，不把模板pending写成confirmed。当前明确任务授权可覆盖必要的可逆本地操作，不为每个常规步骤重复请求许可。

同图、同版本、同语义输入及目标范围复用；只补测受影响部分。请求次数、真实推理、程序重放、素材重用分别计数，未知usage不能当0。不得重启旧调用、旧任务或额度自动化。

每个具体问题先留最小反例、预期/实际、版本和复验条件，最多三轮定点修订；到限意味着该问题需换方法或提交决策，不意味着整个项目自动完成/停工。能独立推进的阶段继续。不能通过换issue名无限重复相同失败。

执行结果分别列语义、视觉、数量、证据和用户反馈。最终报告不把程序通过说成审美准确率，也不因数量不足抹掉真实视觉反馈。[历史与提案边界](../prism_skill_support/references/history-and-proposals.md)区分实跑方法和未验证优化；不得默默启用建议版来冒充历史复现。

本地状态工具不调用模型：
```text
python -B -X utf8 ../prism_skill_support/scripts/workflow.py init --config project.json --out new-run
python -B -X utf8 ../prism_skill_support/scripts/workflow.py status --run new-run
```
输入文件及命令从当前项目定位；脚本可使用绝对路径执行。完成交付或报告确切阻断时保留下一接续点，用户的新追问不自动取消原目标。
