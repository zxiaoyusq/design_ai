# Changelog

## 1.4.0 — 2026-09-02

- 新增按目标视角与活动 profile 执行的字段准入，模型只判断实际可观察、风格需要或用户关注的字段，避免穷举全部 DNA。
- 编译器新增受控值域归一化：显式字段别名、关系描述中的标准关系词以及 0/25/50/75/100 离散刻度全部由宿主确定性整理。
- 低置信、不可见和非法值字段由编译器统一重建 `uncertain_fields` 镜像，不再要求模型机械同步两份数组。
- 模型把 `confidence>=0.75` 的已观察最佳估计误放入 `uncertainties` 时，宿主会在严格 Schema 前提升为普通观察；没有可确认估计时才保守保持为不确定项。
- 风格核心/辅助命中按注册表重新归类；无可用字段、无区域证据或规则闭环不足的标签自动降为 provisional，禁止补造证据保住标签。
- 编译报告新增最终路径到模型观察 JSON Pointer 的源映射，应用失败记录保留结构化问题和完整诊断文件，前端按问题类别展示。
- 新增两组历史失败回归，覆盖必要视角、profile、值域、序数、不确定项同步、风格 allowlist、缺值和区域证据闭环。

## 1.3.0 — 2026-09-02

- 模型阶段改为 `design_dna_multitag_observation_v1` 精简观察协议，最终结果 Schema 保持 v1.1 不变。
- 新增确定性编译器，由字段、风格和关系注册表补全静态元数据、模块结构、排序、候选镜像、统计与可推导证据闭环。
- 模型只保留视觉判断、风格硬判、关系理由和不确定性，避免重复维护大 JSON 中的机械一致性字段。
- 保存入口兼容精简观察结果与已有完整结果，并在最终校验前统一执行幂等整理。
- 新增模型专用精简参考包，将原本分开读取的完整风格与关系注册表压缩为一次只读索引；完整注册表继续作为宿主校验权威。
- 支持宿主把稳定 Skill 上下文作为可缓存系统前缀预装，避免 DeepAgent 为逐文件读取反复调用模型。

## 1.2.0 — 2026-09-02

- 输出 Schema 升级至 `design_dna_multitag_extraction_v1.1`，最终 `style_result` 新增 `derived_style_presets`。
- 新增独立的模型阶段 Schema；模型不读取组合预设，也不生成派生字段。
- 新增 Python 组合派生器，保存前仅依据 confirmed 原子标签确定性覆盖写入组合预设；最终校验器会重算并拒绝伪造或过期值。
- 新增 14 条组合派生规则评测，并收紧“玩趣风格”预设，避免单独鲜彩误触发。

## 1.1.0 — 2026-09-01

- 知识库升级至 4.1，新增玩趣构成、角色拟态、气室膨胀、透明层叠、解构拼装、数字故障、粗野原块和制作式不规整 8 个原子标签。
- 新增 8 个直接可观察 DNA 字段，分别约束原块体量、具象拟态、体量成形、异质系统、结构重组、制作偏差、数字失真与透明层间关系。
- 新增 12 个仅用于查询的命名组合预设；预设不进入 `style_tags`，不参与硬判，也不反向补证。
- 扩充标签关系与异混淆边界，并新增 32 条正例、边界、反例和共存评测，总评测数为 80。

## 1.0.0 — 2026-09-01

- 建立独立的扁平多标签设计 DNA Skill，知识库版本为 4.0。
- 取消结果中的一级/二级及主/次风格结构，统一使用同层稳定 `style_id`。
- 新增 confirmed-only `style_tags`，每图允许 0～3 个独立通过硬门槛的标签，多标签不作为强制目标。
- 分离规则匹配度、结论置信度和相对视觉主导度，并记录标签适用区域。
- 新增标签关系注册表、成对仲裁和组合摘要，阻止硬冲突、重复证据及标签膨胀。
- 保留规范 DNA、三轴状态、profile、必要视角、证据闭环和新 DNA 治理规则。
- 新增多标签共存、排他冲突、暂定候选及单标签回归评测。
- 将无活动依赖的 NordicCalm、PrecisionMinimalism、ArcaneFuture、RefinedWilderness、NeoRetro 调整为 atomic/1；仅保留 MysticOrganic 为 active composite/0。
- 活动风格由 31 个收敛为 30 个；废弃 TribeIdentity，身份信息统一迁移到 IDG-05、IDG-07、IDG-09，不再作为风格标签。
- 新增 `DET-17` 可见细节语法角色，并将 NeoRetro 门槛改为两族独占证据加 `历史造型化`。
- conditional 同区关系显式区分 `forbidden` 与 `independent_evidence`，并校验双方独占核心证据。
- confirmed 标签至少须有一条适用且通过的规则；评测扩为 48 例。
