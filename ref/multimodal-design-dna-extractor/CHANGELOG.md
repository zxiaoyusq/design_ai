# Changelog

## 2.0.0 — 2026-09-01

- 将一级风格改为导航族，二级风格使用稳定 ID、显示名、别名和迁移关系。
- 合并 `QuietElegantLuxury` 与 `RefinedMinimalism`，拆分自然表面与仿生形态，活动风格保持 31 个。
- 将 `NeoRetro` 显示标签改为“复古重组”，排除由通用品类功能件造成的伪复古命中。
- 收紧 `BiomorphicForm`：常规泡罩、气动流线和品类包覆壳不再被当作生长/细胞拓扑。
- 为全部风格统一硬门槛、决定性锚点、独立辅助证据、硬排除及异混淆特征，并增加 8 个集中混淆组。
- 原 MD 六维改为宿主侧兼容别名，模型固定输出空兼容槽；规范 DNA 去重并采用通用核心与品类 profile。
- 分离适用性、可观察性、证据模式与计算状态；材料和工艺只输出视觉候选。
- 升级输出 Schema 至 `design_dna_extraction_v4.0`，收紧风格字段引用、颜色角色、证据、状态和值类型校验。
- 新增 `active_profiles`、必要视角、枚举/比例/语义刻度、风格字段 allowlist 与 M15 排除校验；真别名和零权重兼容推导分开维护。
- 纯字符串标签集统一为 `multi_label`，结构化集合保留 `list`；派生值须闭合全部注册依赖及源证据。
- 当前单图禁用不可表达的 multi-face profile；`CLR-20` 降为辅助字段，不能绕过颜色硬门槛。
- 提取流程改为先观察 DNA、再召回风格和混淆仲裁；M13 语义只在硬判后参与排序。
- Skill 不再负责落盘；结果保存和业务视图转换由宿主应用统一执行。
- 索引改为由本地注册表稳定生成，补充高风险风格对的正例、边界例与反例。
- 业务视图区分 v3/v4 的 M04、M10 语义，并兼容两代中英标签格式。

## 1.2.0 — 2026-08-31

- 新增“异混淆特征”，先覆盖 `KineticEnergy` 与 `SaturatedBold` 的共享表象和决定边界。

## 1.1.1 — 2026-08-31

- 收紧动感能量与个性鲜彩的运动锚点、排除项和冲突仲裁。

## 1.1.0 — 2026-08-30

- 增加完整结果的确定性校验与落盘脚本。

- 同名结果使用递增序号，避免覆盖历史文件。
- 明确完整结果保存后生成同目录业务视图的工程流程。

## 1.0.0 — 2026-08-29

- 增加证据、置信度、不确定字段与知识库外新 DNA 治理协议。
