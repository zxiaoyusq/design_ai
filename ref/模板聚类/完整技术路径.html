从原图到一致性情绪板：v0.6 C 技术路径说明

本稿依据已执行的v0.6-consistency-first-C协议、engine.py及运行输出。C版本自动选出5板，分别含7、6、4、3、3张，合计23个展示位置、23张独立原图，80张未入板。五张主图均由程序计算。只有1板达到7–10张的目标范围；本次没有将其余4板补满，也没有将80张未展示图判为风格不合格。

本轮将103张原图的观察结果转成可执行规则，再由程序生成方向、组织成员、选择主图和控制复用。用户已明确优先保证一致性，因此最多16板、每板最多10张；7–10张保留为展示目标，允许不足7张，正式候选的最小规模设为3张。少于16板或出现3–6张板时如实交付，不放宽距离、改编码或补入未通过图片来凑数。

这里的“自动”指在观察字段和规则冻结之后，成员由程序确定。图像观察由视觉语言模型（LLM）按规范读图并写出结构化判断，规则设计与解释仍需人为决策。这不是本地训练的自动视觉特征网络或深度聚类模型，也没有证明消费者会认可这些搭配。

二、固定七维系数怎样落到18个字段

维度 系数 参与距离的字段 每字段份额
形态 shape 0.28 contour、mass 0.14
纹理 texture 0.22 family、scale、path、coverage 0.055
材质外观与光学 optics 0.17 gloss、transparency、appearance 0.17/3
主体配色 color 0.15 palette、organization、contrast 0.05
构件关系 relation 0.10 assembly、rhythm 0.05
光效 light 0.05 form、extent 0.025
图文场景 context 0.03 setting、dominance 0.015

系数合计1。维内均分是本轮公开的工程选择，并非经过消费者数据校准的感知贡献。图像ID、来源页、文件名、主观标题和反馈标签没有距离权重；SHA256仅用于完全同分时的稳定排序。focus、scope、观察文本和原始构造字段用于来源、准入或解释，不在表中重复累计。

令维度为k，系数为w_k，该维字段集合为F_k。两个不同图像i,j在字段f上的差异区间为[ℓ_f(i,j), u_f(i,j)]。总差异定义为：

L(i,j) = Σₖ wₖ × 本维各字段差异下界的平均 U(i,j) = Σₖ wₖ × 本维各字段差异上界的平均

仅用于排序与主图选择的中点为M(i,j)=[L(i,j)+U(i,j)]/2。各值在0到1之间，越小表示按当前字段编码得到的差异越小。这里不把1−M包装成消费者相似概率或匹配置信度。

两个值都已知时，相同取0，一般名义类别不同取1。协议另外公开以下0.5差异：

  • 轮廓mixed与curved/straight之间取0.5；curved与straight之间取1。
  • 尺度fine–medium–coarse、光泽matte–soft–sharp、透明opaque–translucent–transparent、对比low–medium–high及场景主导程度support–shared–dominant，相邻取0.5、首尾取1。
  • 光学字段的mixed对已知具体类别取0.5。色域的mixed对具体类别取0.5；neutral与warm_muted/cool_muted之间取0.5，其余不同取1。

这些0.5是为了运行规则而指定的类别差异，不表示物理量等距，也不是DNA字典原生提供的数值距离。none是有证据支持的不显著或不适用观察值；null是信息不足，两者不能互换。

三、未知不被相似度吞掉

不同源图比较时，任一方字段为null，该字段差异保留为逻辑区间[0,1]。即使两张图都看不清同一属性，也不能据此认为相同。已知字段不增加权重，未知字段也不默认填成最相似类别。同一原图SHA256的自比较由程序直接返回0，不把自比较的未知当成自身差异。

每图未知权重为：

q(i) = Σₖ [ wₖ / 本维字段数 × 本维未知字段数 ]

协议要求每图未知权重不超过0.30；方向必要字段还必须分别已知。总预算通过，不会让一个未知的必要条件变成通过。0.30是本轮工程门槛，不是统计置信水平。

图对的区间宽度U−L等于至少一方未知的字段所占权重之和。例如只看到表面近景而无法判断整体轮廓和体量，形态维可能带来0.28的区间宽度；不能把这28%悄悄转给纹理。中点将这部分区间折中用于排序，准入仍检查上界。

在0.45阈值下，可以分清三种含义：U≤0.45是按最不利未知取值仍通过；L>0.45是已有差异足以超限；L≤0.45<U是证据不足以保证通过。后一种未通过，不能被解释为已经看到了明确风格冲突。

四、方向由实际组合产生

程序以六类公开模板遍历103张图，枚举实际出现的字段组合。模板是规则族，数据中的组合才是具体方向。因此方向数量不预设为16，也不是将16个已有标题重新填图。C实际产生141个不同方向组合。

所有方向先通过共同条件：未知权重不超过0.30；scope必须为dominant/shared；纹理家族必须已知。非quiet表面还必须为coverage=dominant。表面签名由家族与路径组成；除quiet/fine_surface以外，路径必须已知且相同。这两类的方向签名采用any_path通配，但原始路径仍参与22%纹理距离，不会被从距离中删去。

方向族 必要字段 主要准入边界
形态 form 轮廓、体量、主体色域、表面签名 这些字段同时一致；quiet须再联合已知外观类别并排除other/mixed，平静表面本身不独立支撑正向方向
表面 surface 纹理家族、覆盖、光泽及所需路径 排除quiet，覆盖须为dominant，光泽已知且相同；fine_surface路径通配，其余路径已知且相同；几何平面纹样与不规则纹样分开

方向条件属于必要条件，距离属于总体一致性条件，二者需要同时通过。七维平均接近不能弥补方向核心表达缺失。这也说明最终选择不只由七个百分比决定：门槛、方向模板和复用限制都会影响结果，但它们不是新增的隐藏权重。

一个图像可以符合多个方向族，例如既符合某种形态，也符合某种表面。此时产生重叠候选簇，之后由全局选板和主归属规则处理；不在观察阶段人为决定其最终组别。

五、完全连接如何保证板内两两通过

每个方向内部先将图像视为单元素集合，反复选择允许合并的集合。集合间差异采用完全连接：

D_complete(A,B) = max { U(i,j) : i∈A, j∈B }

只有合并后所有不同图片对的上界均不超过0.45才允许合并。每步在可合并簇对中选择跨簇最大上界最低者；完全同分时按合并后原图SHA256集合的字典序决定。计算比较允许1e−12浮点容差，不用于实质放宽阈值。停止后记录全部簇，再保留规模至少3张者进入候选制作。

这条规则检查的是每一对成员。A与B通过、B与C通过，并不足以让A/B/C自动同板；A与C也要通过。只限制成员到主图的距离不能替代这项检查。

完全连接会偏向紧凑小簇，尤其容易排除未知较多的表面近景。这是选择最不利上界的保守代价，不说明被排除图片没有价值。层级合并和后续贪心也不是所有可能板组合的穷举，因此程序产出的板数不构成“其他算法不可能更多”的证明。

六、主图、截取与全局选板

候选簇C的主图取其medoid，即到簇内其余图片的平均差异中点最小的真实原图：

m_C = argminᵢ∈C [ 到簇内其他图的平均差异中点 ]

完全同分时按源图SHA256稳定排序。公式除以|C|−1表示到其他图的平均；实现将自身0距离也计入并除以|C|，同一候选内两者只差共同常数因子，选出的medoid完全相同。主图不是合成平均图，也不是经消费者验证的最佳设计，只是当前表示中的数值中心。

候选先保留主图，其余先按到主图的差异上界，再按中点、源图SHA256排序。按这个顺序去除同板完全重复图和疑似同设计家族图，再取到最多10张；去重后不足3张则不成候选板。最后在保留集合中按同一medoid规则重算主图，并重新排序。

duplicate_candidates.json登记了091/099这一对“可能同设计家族”，不能确认是同一型号，也不是像素近重复；同板至多保留一张。它是另行披露的展示质量约束，不进入视觉距离、DNA字段或反馈排除规则。C最终5板均未使用这对图片。未进入前10张表示展示上限截取，不能统一记为“不相似”。从已两两合格的簇取子集不会破坏成对门槛。

相同成员集合只保留一个候选，优先采用涉及维度系数和较高的解释，完全同分再按方向键排序；成员集合本身不改变。

全局选择在这些候选板之间运行，最多选16板。每次先剔除违反约束的候选，再按以下优先级贪心选择：新增独立图片数更多；与已选板的最大重合更低；板内平均差异上界更低；方向涉及维度的系数和更高；成员更多；方向键与原图SHA256集合字典序。涉及维度的系数和只作同级候选优先级，不修改七维距离：形态为形态＋纹理＋配色，quiet形态再加光学；表面为纹理＋光学；外观为光学＋配色＋纹理；配色为配色＋纹理；构件为构件关系＋纹理；光效为光效＋配色＋纹理。

采用的硬约束为：每图最多展示2次；每新板至少增加2张此前未展示图片；任意两板的Jaccard重合不超过1/3。板A,B的重合定义为：

J(A,B) = |A∩B| / |A∪B| ≤ 1/3

Jaccard不是固定“最多共3张”。例如两张7图板共3张时为3/11，可以通过；共4张时为4/10，不能通过。它直接考虑板的大小，因此适用于本轮3–10张的可变规模。

选择在达到16板或没有合格新增候选时停止。没有追求填满空位的默认补图流程，也不以蓝圈排除数量挑选阈值。贪心选择是可复算的工程方案，不能声称已找到全局最优覆盖。

七、唯一主归属与展示复用分开

对至少出现在一张选中板中的图像，比较其到各出现板主图的距离中点，最近者成为唯一主归属；完全同分按稳定板ID排序。其他出现位置标记为展示复用。归属范围只包括实际展示该图的板。任何未入板图像都不强行指派到一个看似最近的板；程序以R00记未入板状态，不把R00当作新的风格簇。C最终没有跨板复用，因此23张展示图各自所属板就是其主归属。

因此应分别报告三种数量：选中板的展示总位置、实际使用的独立图片数、103图中未展示的数量。展示总位置会因复用大于独立图片数，不能混写成覆盖率。

未展示的原因应依据运行记录说明：必要字段未知、核心条件不符、图对上界不能保证通过、候选簇规模不足3、每候选10张上限、复用/重合/新增覆盖限制或全局候选未被选中。多种原因可以同时存在；“没有展示”不等于“已判不相似”。

十一、人机边界与尚未证明的内容

LLM视觉观察负责按规范读取原图，描述可见轮廓、表面、配色与构件，并记录图像估计及未知；规范设计、规则选择、解释措辞和复核边界需要人为决策。LLM内部具有视觉能力，不代表本项目训练或部署了专门的自动特征网络。本次没有目标检测器、像素分割、端到端视觉嵌入、表示学习损失函数或深度聚类训练过程。

软件引擎负责18字段运算、方向枚举、完全连接、主图选择、全局约束、归属和可追溯输出。它读取离散观察JSON，无法独立从一张新图片恢复这些字段；面对新图仍要先通过同规范观察与证据记录。对于同一冻结输入，程序的决定可以复算；重新读图可能产生不同观察，两者不能混称为同一个“自动化”能力。

成员冻结后才写名称、核心表达与差异范围。视觉核查如果发现观察证据错误，应保留修正原因和版本并整批重跑；不能直接手工替换最终成员，再称为原算法结果。C当前输入冲突已按统一规则暂缓，没有为数量目标回改这些观察。

本轮新观察者在编码时不读取旧板、旧编码结果或蓝圈反馈；算法设计者已经知道既有反馈，所以整体是反馈启发的方法迭代。技术文稿作者可在观察完成后阅读历史报告，但这不授权按成绩回改观察。新成员生成后若比较旧25个问题搭配，只属于内部回看；旧主图未在新板出现的搭配应记“不可比”，不能用“没有展示”宣称已纠正。

主要局限仍在输入与有效性上：原图短边约236像素，真实材料、触感、工艺和发光机制通常不能确认；主导单值编码压缩了次要表达，不同观察者可能给出不同值；形态、纹理与材质外观字段也未必独立。完全连接和未知上界会牺牲覆盖，全局贪心不保证最优，阈值和类别差异尚未经过独立感知校准。
